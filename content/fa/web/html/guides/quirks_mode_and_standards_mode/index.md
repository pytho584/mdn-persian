# درک حالت‌های Quirks و استاندارد

در روزهای اولیه وب، صفحات معمولاً در دو نسخه نوشته می‌شدند: یکی برای Netscape Navigator و یکی برای Microsoft Internet Explorer. وقتی استانداردهای وب در W3C تدوین شد، مرورگرها نمی‌توانستند مستقیماً از آن‌ها استفاده کنند، چون این کار تقریباً همه سایت‌های موجود را از کار می‌انداخت. به همین دلیل مرورگرها دو حالت معرفی کردند تا سایت‌های سازگار با استانداردهای جدید را از سایت‌های قدیمی و legacy جدا کنند.

امروزه موتورهای چیدمان مرورگرها از سه حالت استفاده می‌کنند: **quirks mode**، **limited-quirks mode** و **no-quirks mode**. در **quirks mode**، چیدمان صفحه شبیه رفتار Navigator 4 و Internet Explorer 5 است. این حالت برای پشتیبانی از سایت‌هایی که قبل از پذیرش گسترده استانداردهای وب ساخته شده‌اند ضروری است. در **no-quirks mode**، رفتار دقیقاً همان چیزی است که مشخصات مدرن HTML و CSS توصیف می‌کنند. در **limited-quirks mode** تنها تعداد بسیار کمی از رفتارهای غیراستاندارد پیاده‌سازی شده است.

حالت‌های limited-quirks و no-quirks قبلاً به‌ترتیب «almost-standards» و «full standards» نامیده می‌شدند. این نام‌ها تغییر کرده‌اند چون رفتار آن‌ها اکنون استاندارد شده است.

## مرورگرها چگونه تشخیص می‌دهند کدام حالت استفاده شود؟

برای اسناد [HTML](/en-US/docs/Web/HTML)، مرورگرها با توجه به doctype ابتدای سند تصمیم می‌گیرند که آن را در حالت quirks یا no-quirks پردازش کنند. برای اطمینان از اینکه صفحه شما در حالت no-quirks بارگذاری می‌شود، باید doctype مثل مثال زیر در ابتدای صفحه داشته باشید:

```html
<!doctype html>
<html lang="en">
  <head>
    <meta charset="UTF-8" />
    <title>Hello World!</title>
  </head>
  <body></body>
</html>
```

Doctype نشان‌داده‌شده در مثال، یعنی `<!doctype html>`، ساده‌ترین شکل ممکن و همان چیزی است که استانداردهای فعلی HTML توصیه می‌کنند. نسخه‌های قدیمی‌تر استاندارد HTML انواع دیگری را پیشنهاد می‌دادند، اما امروزه همه مرورگرها این doctype را به‌عنوان no-quirks mode تفسیر می‌کنند. هیچ دلیل معتبری برای استفاده از doctype پیچیده‌تر وجود ندارد. اگر از doctype دیگری استفاده کنید، ممکن است به‌طور ناخواسته حالتی را انتخاب کنید که limited-quirks یا quirks را فعال کند.

Doctype را دقیقاً در ابتدای سند HTML و قبل از هر محتوای دیگری قرار دهید.

تنها هدف `<!doctype html>` فعال‌کردن no-quirks mode است. در نسخه‌های قدیمی‌تر استاندارد HTML، doctype معانی دیگری هم داشت، اما هیچ مرورگری هرگز از doctype برای چیز دیگری به‌جز تغییر بین حالت‌های رندر استفاده نکرده است.

توضیحات مفصل‌تر درباره [زمان انتخاب حالت‌های مختلف توسط مرورگرها](https://hsivonen.fi/doctype/) در دسترس است.

### XHTML

اگر صفحه خود را به‌صورت [XHTML](/en-US/docs/Glossary/XHTML) و با MIME type `application/xhtml+xml` در هدر HTTP `Content-Type` ارائه کنید، برای فعال‌شدن no-quirks mode نیازی به doctype ندارید؛ چون چنین اسنادی همیشه در حالت no-quirks پردازش می‌شوند.

اگر محتوای شبیه XHTML را با MIME type `text/html` ارائه کنید، مرورگرها آن را به‌عنوان HTML می‌خوانند و برای استفاده از no-quirks mode به doctype نیاز دارید.

## چطور بفهمیم کدام حالت استفاده شده؟

اگر صفحه در حالت quirks یا limited-quirks رندر شود، فایرفاکس یک هشدار در تب Console ابزار توسعه‌دهنده ثبت می‌کند. اگر این هشدار نمایش داده نشود، فایرفاکس از no-quirks mode استفاده می‌کند.

مقدار `document.compatMode` در جاوااسکریپت مشخص می‌کند که سند در حالت quirks است یا نه. اگر مقدار آن `"BackCompat"` باشد، سند در حالت quirks است. در غیر این صورت مقدار آن `"CSS1Compat"` خواهد بود.
