**کلیدواژهٔ `compression-dictionary`** برای attribute `rel` در element `<link>` یک link است که browserها می‌توانند از آن برای دانلود یک compression dictionary استفاده کنند. این dictionary برای فشرده‌سازی دانلودهای آیندهٔ منابع همین سایت به کار می‌رود و حجم دانلود این منابع را نسبت به فشرده‌سازی معمولی کاهش می‌دهد.

**توجه:** اگر وب‌سایت هدر `Content-Security-Policy` داشته باشد، directive `connect-src` (یا `default-src` اگر `connect-src` تنظیم نشده باشد) باید مکان منبع dictionary را مجاز کند؛ در غیر این صورت درخواست مسدود خواهد شد.

برای اطلاعات بیشتر، [Compression Dictionary Transport guide](/en-US/docs/Web/HTTP/Guides/Compression_dictionary_transport) را ببینید.
