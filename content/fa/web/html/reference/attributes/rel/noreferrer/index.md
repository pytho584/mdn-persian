# مقدار attribute با `rel="noreferrer"`

کلیدواژهٔ **`noreferrer`** در attribute [`rel`](/en-US/docs/Web/HTML/Reference/Attributes/rel) عناصر `<a>`، `<area>` و `<form>` به مرورگر می‌گوید هنگام ناوبری به منبع مقصد، هدر `Referer` را حذف کند و به هیچ شکل دیگری اطلاعات referrer را فاش نکند. همچنین این کلیدواژه باعث می‌شود مرورگر طوری رفتار کند که گویی کلیدواژهٔ [`noopener`](/en-US/docs/Web/HTML/Reference/Attributes/rel/noopener) نیز مشخص شده باشد.
