کلیدواژهٔ **`dns-prefetch`** برای attribute به نام `rel` در element ی `<link>`، اشاره‌ای به browser است که کاربر احتمالاً به منابعی از origin مقصد نیاز خواهد داشت؛ بنابراین browser می‌تواند با انجام DNS resolution از پیش برای آن origin، تجربهٔ کاربری را بهبود بخشد.

برای جزئیات بیشتر، [استفاده از dns-prefetch](/en-US/docs/Web/Performance/Guides/dns-prefetch) را ببینید.
