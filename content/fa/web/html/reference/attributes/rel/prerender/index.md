> **منسوخ‌شده و غیراستاندارد:** این قابلیت دیگر توصیه نمی‌شود.

کلیدواژهٔ `prerender` برای attribute [`rel`](/en-US/docs/Web/HTML/Reference/Elements/link#rel) از element [`<link>`](/en-US/docs/Web/HTML/Reference/Elements/link) به browser اشاره می‌کند که کاربر احتمالاً در ناوبری بعدی به منبع هدف نیاز خواهد داشت؛ بنابراین browser می‌تواند با واکشی و پردازش پیشدستانهٔ منبع، تجربهٔ کاربری را بهبود دهد — برای مثال، با واکشی زیرمنابع (subresources) آن یا انجام بخشی از رندر در پس‌زمینه (offscreen).

این قابلیت توسط [Speculation Rules API](/en-US/docs/Web/API/Speculation_Rules_API) جایگزین شده است.
