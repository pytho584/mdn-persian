کلیدواژهٔ **`me`** برای ویژگیِ (attribute) [`rel`](/en-US/docs/Web/HTML/Reference/Elements/link#rel) در عناصر `<link>` و `<a>` به این معنی است که منبع فعلی نمایندهٔ همان شخص یا موجودیتی است که مقصدِ لینک معرفی می‌کند. مقدار `me` اولین بار در [مشخصات XHTML Friends Network (XFN)](https://gmpg.org/xfn/) معرفی شد.

```html
<link rel="me" href="example.com" />
```

ویژگی `rel="me"` در مشخصات [RelMeAuth](https://microformats.org/wiki/RelMeAuth) و [Web sign in](https://microformats.org/wiki/web-sign-in) استفاده می‌شود. این ویژگی به افراد اجازه می‌دهد با استفاده از نام دامنه یا یک URL خاص، هویت خود را به یک سرویس وب معرفی کنند.

## مشخصات

مشخصات این مقدار در [XFN](https://www.gmpg.org/xfn/11#me) تعریف شده است.

## سازگاری مرورگر

سازگاری مرورگر در این مورد مطرح نیست، زیرا `rel="me"` توسط سرویس‌های وب استفاده می‌شود، نه مرورگرها.
