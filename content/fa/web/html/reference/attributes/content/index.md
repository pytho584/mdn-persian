attribute **`content`** مقدار یک نام متادیتا را تعیین می‌کند که توسط attribute `name` در element `<meta>` تعریف شده است. این attribute یک رشته (string) می‌گیرد و ساختار (syntax) آن با توجه به مقدار `name` متفاوت است.

## مقدار

انواع مقادیری که attribute `content` می‌پذیرد به مقدار `name` بستگی دارد. برای جزئیات بیشتر درباره فرمت‌ها و انواع خاص، صفحهٔ [attribute `name` در `<meta>`](/en-US/docs/Web/HTML/Reference/Elements/meta/name) را ببینید.

## نمونه‌ها

### تنظیم توضیح متا (meta description) برای سند

تگ `<meta>` زیر از `name=description` برای تنظیم «توضیح متا» برای یک سند استفاده می‌کند. attribute `content` مقدار این متادیتا را فراهم می‌کند:

```html
<meta
  name="description"
  content="The HTML reference describes all elements and attributes of HTML, including global attributes that apply to all elements." />
```
