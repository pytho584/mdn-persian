ویژگی سراسری `inert` یک ویژگی بولی (Boolean) است که مشخص می‌کند عنصر و تمام زیرشاخه‌های درخت تخت (flat tree descendants) آن **inert** (غیرفعال) شوند. این ویژگی را می‌توان به بخش‌هایی از محتوا اضافه کرد که نباید تعاملی (interactive) باشند. وقتی یک عنصر inert است، به همراه تمام فرزندانش (از جمله عناصر تعاملی معمولی مثل لینک‌ها، دکمه‌ها و کنترل‌های فرم) غیرفعال می‌شود چون نمی‌توانند فوکوس دریافت کنند یا روی آن‌ها کلیک کرد. همچنین می‌توان `inert` را به عناصری که باید خارج از صفحه یا پنهان باشند اضافه کرد. یک عنصر inert به همراه زیرشاخه‌هایش از ترتیب تب (tab order) و درخت دسترسی‌پذیری (accessibility tree) حذف می‌شود.

dialogهای modal که با [`showModal()`](/en-US/docs/Web/API/HTMLDialogElement/showModal) ایجاد می‌شوند از حالت inert خارج می‌شوند – یعنی از اجداد خود ارث‌بری نمی‌کنند، اما می‌توان با تنظیم صریح ویژگی `inert` روی خود آن‌ها را inert کرد. هیچ عنصر دیگری نمی‌تواند از حالت inert خارج شود.

> [!NOTE]
> هرچند `inert` یک ویژگی سراسری است و می‌توان روی هر عنصری اعمال کرد، معمولاً برای بخش‌های محتوا استفاده می‌شود. برای غیرفعال کردن کنترل‌های تکی، بهتر است از ویژگی [`disabled`](/en-US/docs/Web/HTML/Reference/Attributes/disabled) همراه با استایل‌های CSS {{cssxref(":disabled")}} استفاده کنید.

عناصر HTML inert و زیرشاخه‌های درخت تخت آن‌ها:

- رویدادهای {{domxref("Element/click_event", "click")}} را هنگام کلیک شدن فعال نمی‌کنند.
- نمی‌توانند فوکوس بگیرند و رویدادهای {{domxref("Element/focus_event", "focus")}} روی آن‌ها فعال نمی‌شود.
- در قابلیت جستجوی درون صفحه (find-in-page) مرورگر قابل جستجو نیستند (هیچ محتوایی از آن‌ها پیدا/مطابقت داده نمی‌شود).
- کاربر نمی‌تواند متن درون محتوای آن‌ها را انتخاب کند – مشابه استفاده از ویژگی CSS {{cssxref("user-select")}} برای غیرفعال کردن انتخاب متن.
- محتوای قابل ویرایش (مانند فیلدهای متنی `<input>` و عناصر متنی با [`contenteditable`](/en-US/docs/Web/HTML/Reference/Global_attributes/contenteditable)) قابل ویرایش نیستند.
- از فناوری‌های کمکی (assistive technologies) پنهان می‌شوند چون از درخت دسترسی‌پذیری حذف می‌شوند.

ویژگی‌های دیگری نیز می‌توانند یک عنصر و زیرشاخه‌هایش را به حالت inert ببرند:

- ویژگی CSS {{cssxref("interactivity")}}
- خاصیت DOM {{domxref("HTMLElement.inert")}}

## نکات دسترسی‌پذیری

در استفاده از ویژگی `inert` به دسترسی‌پذیری دقت کنید. به‌طور پیش‌فرض هیچ روش بصری برای تشخیص inert بودن یک عنصر یا زیردرخت آن وجود ندارد. به‌عنوان توسعه‌دهنده، وظیفه شماست که بخش‌های فعال و بخش‌های inert محتوا را به وضوح مشخص کنید.

در حین ارائه نشانه‌های بصری و غیربصری درباره inert بودن محتوا، به یاد داشته باشید که نمای دیداری (viewport) ممکن است تنها بخشی از محتوا را نشان دهد. کاربران ممکن است به بخش کوچکی از محتوا بزرگنمایی کرده باشند یا اصلاً نتوانند محتوا را ببینند. بخش‌های inert که به وضوح مشخص نیستند می‌توانند باعث ناامیدی و تجربه کاربری بد شوند.

## مثال‌ها

در این مثال، دومین `<div>` و تمام زیرشاخه‌هایش با استفاده از ویژگی `inert` غیرفعال شده‌اند:

```html
<div>
  <label for="button1">دکمه ۱</label>
  <button id="button1">من inert نیستم</button>
</div>
<div inert>
  <label for="button2">دکمه ۲</label>
  <button id="button2">من inert هستم</button>
</div>
```
