ویژگی سراسری `inert` (غیرفعال‌سازی) یک ویژگی (attribute) بولی است که مشخص می‌کند عنصر و همهٔ فرزندانِ درختِ مسطح آن «inert» (غیرفعال) شوند. می‌توان این ویژگی را به بخش‌هایی از محتوا که نباید تعاملی باشند اضافه کرد. وقتی یک عنصر `inert` است، خودش و همهٔ نوادگانش – از جمله عناصر معمولاً تعاملی مثل لینک‌ها، دکمه‌ها و کنترل‌های فرم – غیرفعال می‌شوند؛ چون نمی‌توانند focus بگیرند یا کلیک شوند. همچنین می‌توان `inert` را به عناصری که باید خارج از دید یا پنهان باشند اضافه کرد. یک عنصر `inert` همراه با نوادگانش از ترتیب تب (tab order) و درخت دسترسی (accessibility tree) حذف می‌شود.

دیالوگ‌های مدال (modal dialog) که با [`showModal()`](/en-US/docs/Web/API/HTMLDialogElement/showModal) ساخته می‌شوند از حالت غیرفعال خارج می‌شوند؛ یعنی از `inert` بودن اجدادشان ارث نمی‌برند، اما اگر خودشان ویژگی `inert` را به‌صراحت داشته باشند، می‌توانند غیرفعال شوند. هیچ عنصر دیگری نمی‌تواند از حالت غیرفعال خارج شود.

> **نکته:** اگرچه `inert` یک ویژگی سراسری است و می‌تواند روی هر عنصری اعمال شود، معمولاً برای بخش‌هایی از محتوا استفاده می‌شود. برای غیرفعال کردن کنترل‌های تکی، بهتر است از ویژگی [`disabled`](/en-US/docs/Web/HTML/Reference/Attributes/disabled) به همراه CSS {{cssxref(":disabled")}} استفاده کنید.

عناصر HTML `inert` و نوادگان درخت مسطح آن‌ها:

- رویدادهای {{domxref("Element/click_event", "click")}} هنگام کلیک روی آن‌ها فعال نمی‌شوند.
- نمی‌توانند focus بگیرند و رویدادهای {{domxref("Element/focus_event", "focus")}} روی آن‌ها فعال نمی‌شوند.
- با قابلیت جستجوی درون‌صفحه‌ای مرورگر (find-in-page) پیدا نمی‌شوند (هیچ محتوایی از آن‌ها جستجو/تطبیق داده نمی‌شود).
- کاربر نمی‌تواند متن داخل محتوای آن‌ها را انتخاب کند – مشابه استفاده از ویژگی CSS {{cssxref("user-select")}} برای غیرفعال کردن انتخاب متن.
- محتوای قابل ویرایش (مثل فیلدهای متنی `<input>` یا عناصر دارای [`contenteditable`](/en-US/docs/Web/HTML/Reference/Global_attributes/contenteditable)) قابل ویرایش نیست.
- از فناوری‌های کمکی پنهان می‌شوند، زیرا از درخت دسترسی حذف می‌شوند.

دو ویژگی دیگر نیز می‌توانند یک عنصر و نوادگانش را به حالت `inert` ببرند:

- ویژگی CSS {{cssxref("interactivity")}}
- ویژگی DOM {{domxref("HTMLElement.inert")}}

## ملاحظات دسترسی

هنگام استفاده از ویژگی `inert`، ملاحظات دسترسی را جدی بگیرید. به طور پیش‌فرض هیچ راه بصری برای تشخیص `inert` بودن یک عنصر یا زیردرخت آن وجود ندارد. به عنوان یک توسعه‌دهندهٔ وب، وظیفهٔ شماست که به‌روشنی مشخص کنید کدام بخش‌های محتوا فعال و کدام غیرفعال هستند.

علاوه بر ارائهٔ نشانه‌های بصری و غیربصری دربارهٔ غیرفعال بودن، به یاد داشته باشید که viewport ممکن است فقط بخشی از محتوا را نشان دهد. کاربران ممکن است به بخش کوچکی از محتوا زوم کرده باشند یا اصلاً نتوانند محتوا را ببینند. بخش‌های `inert` که به‌وضوح مشخص نیستند، می‌توانند باعث سردرگمی و تجربهٔ کاربری بد شوند.

## مثال‌ها

در این مثال، دومین `<div>` و همهٔ نوادگانش با ویژگی `inert` غیرفعال شده‌اند:

```html
<div>
  <label for="button1">دکمه ۱</label>
  <button id="button1">من غیرفعال نیستم</button>
</div>
<div inert>
  <label for="button2">دکمه ۲</label>
  <button id="button2">من غیرفعال هستم</button>
</div>
```
