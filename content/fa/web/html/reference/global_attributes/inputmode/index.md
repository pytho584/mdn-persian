## ویژگی سراسری `inputmode` در HTML

ویژگی سراسری `inputmode` یک ویژگی شمارشی (enumerated) است که به مرورگر اشاره می‌کند کاربر چه نوع داده‌ای را هنگام ویرایش المان یا محتوای آن وارد خواهد کرد. این کار به مرورگر اجازه می‌دهد صفحه‌کلید مجازی مناسبی را نمایش دهد.

این ویژگی عمدتاً روی المان‌های `<input>` استفاده می‌شود، اما روی هر المنی که در حالت `contenteditable` قرار دارد نیز قابل استفاده است.

توجه کنید که ویژگی `inputmode` هیچ الزام اعتباری (validity) روی ورودی اعمال نمی‌کند. برای اعمال الزام بر اساس نوع داده مشخص، باید نوع `<input>` مناسب را انتخاب کنید. برای راهنمایی دقیق درباره انتخاب نوع `<input>`، بخش [مقادیر](#value) را ببینید.

## مقدار

ویژگی می‌تواند هر یک از مقادیر زیر را داشته باشد:

- `none`
  - بدون صفحه‌کلید مجازی. برای مواقعی که صفحه خودش کنترل ورودی صفحه‌کلید را پیاده‌سازی می‌کند.
- `text` (مقدار پیش‌فرض)
  - صفحه‌کلید استاندارد ورودی برای زبان محلی کاربر.
- `decimal`
  - صفحه‌کلید ورودی اعداد اعشاری شامل ارقام و جداکننده اعشار برای زبان محلی کاربر (معمولاً `.` یا `,`). دستگاه‌ها ممکن است کلید منفی (`-`) را نشان بدهند یا ندهند.
- `numeric`
  - صفحه‌کلید ورودی عددی، اما فقط به ارقام ۰–۹ نیاز دارد. دستگاه‌ها ممکن است کلید منفی را نشان بدهند یا ندهند.
- `tel`
  - صفحه‌کلید تلفن، شامل ارقام ۰–۹، ستاره (`*`) و مربع (`#`). ورودی‌هایی که نیاز به شماره تلفن دارند معمولاً باید از `<input type="tel">` استفاده کنند.
- `search`
  - صفحه‌کلید مجازی بهینه‌شده برای ورودی جستجو. برای مثال، کلید بازگشت/ارسال ممکن است برچسب "جستجو" داشته باشد، همراه با بهینه‌سازی‌های دیگر. ورودی‌هایی که نیاز به عبارت جستجو دارند معمولاً باید از `<input type="search">` استفاده کنند.
- `email`
  - صفحه‌کلید مجازی بهینه‌شده برای وارد کردن آدرس ایمیل. معمولاً شامل کاراکتر `@` و دیگر بهینه‌سازی‌ها است. ورودی‌هایی که نیاز به آدرس ایمیل دارند معمولاً باید از `<input type="email">` استفاده کنند.
- `url`
  - صفحه‌کلید بهینه‌شده برای وارد کردن URL. برای مثال ممکن است کلید `/` پررنگ‌تر باشد. امکانات پیشرفته می‌تواند شامل دسترسی به تاریخچه و غیره باشد. ورودی‌هایی که نیاز به URL دارند معمولاً باید از `<input type="url">` استفاده کنند.
