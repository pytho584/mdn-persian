**`dir`** یک [ویژگی سراسری](/en-US/docs/Web/HTML/Reference/Global_attributes) است؛ یک ویژگی [شمارشی](/en-US/docs/Glossary/Enumerated) که جهت متن عنصر را مشخص می‌کند.

```html interactive-example
<p dir="rtl">
  This paragraph is in English but incorrectly goes right to left.
</p>
<p dir="ltr">This paragraph is in English and correctly goes left to right.</p>

<hr />

<p>هذه الفقرة باللغة العربية ولكن بشكل خاطئ من اليسار إلى اليمين.</p>
<p dir="auto">
  هذه الفقرة باللغة العربية ، لذا يجب الانتقال من اليمين إلى اليسار.
</p>
```

این ویژگی می‌تواند مقادیر زیر را داشته باشد:

- `ltr` یعنی _چپ‌به‌راست_؛ برای زبان‌هایی استفاده می‌شود که از چپ به راست نوشته می‌شوند (مثل انگلیسی)؛
- `rtl` یعنی _راست‌به‌چپ_؛ برای زبان‌هایی استفاده می‌شود که از راست به چپ نوشته می‌شوند (مثل عربی)؛
- `auto`؛ این مقدار به عامل کاربر (user agent) اجازه می‌دهد تصمیم بگیرد. عامل کاربر با یک الگوریتم پایه، کاراکترهای داخل عنصر را بررسی می‌کند تا به کاراکتری با جهت‌دهی قوی برسد؛ سپس همان جهت را به کل عنصر اعمال می‌کند.

> [!NOTE]
> مقدار `auto` باید برای داده‌هایی استفاده شود که جهت آن‌ها مشخص نیست؛ مثل داده‌هایی که از ورودی کاربر یا منابع خارجی می‌آیند.

اگر این ویژگی تنظیم نشده باشد، مقدار آن از عنصر والد [به ارث برده می‌شود](#inheritance).

این ویژگی می‌تواند توسط خواص CSS یعنی `direction` و `unicode-bidi` بازنویسی شود، اگر صفحه‌ی CSS فعال باشد و عنصر از این خواص پشتیبانی کند.

چون جهت‌بندی متن از نظر معنایی به محتوای آن مربوط است نه به نمایش آن، توصیه می‌شود توسعه‌دهندگان وب تا حد امکان از این ویژگی به‌جای خواص CSS مرتبط استفاده کنند. به این ترتیب، متن حتی در مرورگری که از CSS پشتیبانی نمی‌کند یا CSS در آن غیرفعال است، به‌درستی نمایش داده می‌شود.

## ارث‌بری

اگر عنصری ویژگی `dir` نداشته باشد، مقدار `dir` تنظیم‌شده روی [گره والد](/en-US/docs/Glossary/Node/DOM) خود را به ارث می‌برد؛ والد آن هم ممکن است این مقدار را از والد خود به ارث برده باشد و همین‌طور ادامه پیدا می‌کند.

## نکات استفاده

یک تصویر می‌تواند ویژگی `dir` را با مقدار `"rtl"` داشته باشد؛ در این صورت ویژگی‌های HTML یعنی `title` و `alt` نیز با جهت `"rtl"` قالب‌بندی و تعریف می‌شوند.

وقتی جدولی ویژگی `dir` را با مقدار `"rtl"` داشته باشد، ترتیب ستون‌ها از راست به چپ چیده می‌شود.

این ویژگی برای عنصر `<bdo>` اجباری است و در آن معنای متفاوتی دارد.

این ویژگی توسط عنصر `<bdi>` به ارث برده _نمی‌شود_. اگر تنظیم نشده باشد، مقدار آن `auto` است.

مرورگرها ممکن است به کاربران اجازه دهند جهت عناصر `<input>` و `<textarea>` را تغییر دهند تا به تولید محتوا کمک کنند.
کروم و سافاری گزینه‌ای برای جهت در منوی راست‌کلیک فیلدهای ورودی ارائه می‌دهند.
فایرفاکس از کلیدهای <kbd>Ctrl</kbd> (ویندوز)/<kbd>Cmd</kbd> (مک) + <kbd>Shift</kbd> + <kbd>X</kbd> داخل یک `<textarea>` برای تغییر جهت متن استفاده می‌کند.
این قابلیت‌ها مقدار ویژگی `dir` را بین `ltr` و `rtl` جابه‌جا می‌کنند.
