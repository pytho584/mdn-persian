این مرجع [HTML](/en-US/docs/Web/HTML) همه **element‌ها** و **attributeهای** HTML را توضیح می‌دهد، از جمله **global attributes** که روی همه element‌ها اعمال می‌شوند.

- [مرجع element‌های HTML](/en-US/docs/Web/HTML/Reference/Elements)
  - : این صفحه همه element‌های HTML را فهرست می‌کند که با استفاده از تگ‌ها ساخته می‌شوند.
- [مرجع attributeهای HTML](/en-US/docs/Web/HTML/Reference/Attributes)
  - : element‌ها در HTML دارای attributeهایی هستند؛ این مقادیر اضافی، element‌ها را پیکربندی می‌کنند یا رفتارشان را به‌شکل‌های مختلف برای برآوردن نیازهای کاربران تنظیم می‌کنند.
- [Global attributes](/en-US/docs/Web/HTML/Reference/Global_attributes)
  - : Global attributes، attribute‌های مشترک بین همه element‌های HTML هستند؛ می‌توان از آن‌ها روی همه element‌ها استفاده کرد، هرچند ممکن است روی برخی بی‌اثر باشند.
- [دسته‌های محتوا (Content categories)](/en-US/docs/Web/HTML/Guides/Content_categories)
  - : هر element در HTML عضو یک یا چند Content category است؛ این دسته‌بندی‌ها element‌هایی را که ویژگی‌های مشترکی دارند گروه‌بندی می‌کنند.
- [کامنت‌های HTML](/en-US/docs/Web/HTML/Guides/Comments)
  - : کامنت‌های HTML برای افزودن یادداشت‌های توضیحی به markup یا جلوگیری از تفسیر بخش‌های خاصی از سند توسط مرورگر استفاده می‌شوند.
- [فرمت‌های تاریخ و زمان در HTML](/en-US/docs/Web/HTML/Guides/Date_and_time_formats)
  - : بعضی از element‌های HTML به شما امکان می‌دهند تاریخ و/یا زمان را به‌عنوان مقدار خود element یا مقدار یک attribute مشخص کنید. این شامل انواع مختلف تاریخ و زمان در element `<input>` و همچنین elementهای `<ins>` و `<del>` است.
