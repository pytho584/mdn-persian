# عنصر `<font>` در HTML

عنصر **`<font>`** در [HTML](/en-US/docs/Web/HTML) اندازه، رنگ و قلم (face) محتوای خود را تعیین می‌کند.

> [!WARNING]
> از این عنصر استفاده نکنید. برای استایل‌دهی متن از ویژگی‌های CSS [Fonts](/en-US/docs/Web/CSS/Guides/Fonts) استفاده کنید.

## ویژگی‌ها

مانند سایر عناصر HTML، این عنصر از [ویژگی‌های سراسری](/en-US/docs/Web/HTML/Reference/Global_attributes) پشتیبانی می‌کند.

- `color` (منسوخ، غیراستاندارد)
  - : این ویژگی رنگ متن را با استفاده از یک نام رنگ یا رنگی در قالب هگزادسیمال `#RRGGBB` تنظیم می‌کند.
- `face` (منسوخ، غیراستاندارد)
  - : این ویژگی شامل فهرستی از یک یا چند نام فونت است که با کاما از هم جدا شده‌اند. متن سند در سبک پیش‌فرض با اولین فونتی که مرورگر کاربر پشتیبانی می‌کند رندر می‌شود. اگر هیچ فونتی از آن فهرست روی سیستم محلی نصب نباشد، مرورگر معمولاً از فونت `proportional` یا `fixed-width` همان سیستم استفاده می‌کند.
- `size` (منسوخ، غیراستاندارد)
  - : این ویژگی اندازه فونت را به صورت عددی یا نسبی تعیین می‌کند. مقادیر عددی از `1` تا `7` هستند که `1` کوچک‌ترین و `3` مقدار پیش‌فرض است. همچنین می‌توان آن را با مقدار نسبی مانند `+2` یا `-3` تعریف کرد که نسبت به مقدار پیش‌فرض `3` تنظیم می‌شود.

## اینترفیس DOM

این عنصر اینترفیس `HTMLFontElement` را پیاده‌سازی می‌کند.
