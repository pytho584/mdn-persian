## ریشهٔ اصلی

| Element | توضیحات |
| ------- | ------- |
| `<html>` | نشان‌دهندهٔ ریشه (element سطح بالا) یک سند HTML است؛ بنابراین به آن _root element_ نیز گفته می‌شود. همهٔ elementهای دیگر باید از نوادگان (descendants) این element باشند. |

## فرادادهٔ سند

فراداده شامل اطلاعاتی دربارهٔ صفحه است. این شامل اطلاعاتی دربارهٔ استایل‌ها، اسکریپت‌ها و داده‌ها برای کمک به نرم‌افزارها (موتورهای جستجو، مرورگرها و غیره) در استفاده و رندر کردن صفحه است. فراداده برای استایل‌ها و اسکریپت‌ها ممکن است در خود صفحه تعریف شود یا به فایل دیگری که این اطلاعات را دارد لینک شود.

> [!NOTE]
> برای اطلاعات بیشتر دربارهٔ اصول اولیهٔ elementها و attributeهای HTML، به [آناتومی یک element در HTML](/en-US/docs/Learn_web_development/Core/Structuring_content/Basic_HTML_syntax#anatomy_of_an_html_element) مراجعه کنید.

| المان                   | توضیحات                                                                                                                                                                                                                                                                                                       |
| ----------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `<base>`                | URL پایه را برای همه URLهای نسبی در سند مشخص می‌کند. فقط یک عدد از این المان می‌تواند در سند وجود داشته باشد.                                                                                                                                                                                                  |
| `<head>`                | شامل اطلاعات قابل خواندن برای ماشین (metadata) دربارهٔ سند است، مانند [title](https://developer.mozilla.org/en-US/docs/Web/HTML/Reference/Elements/title)، [script](https://developer.mozilla.org/en-US/docs/Web/HTML/Reference/Elements/script) و [style sheet](https://developer.mozilla.org/en-US/docs/Web/HTML/Reference/Elements/style). |
| `<link>`                | روابط بین سند فعلی و یک منبع خارجی را مشخص می‌کند. این المان بیشتر برای پیوند دادن به CSS استفاده می‌شود، اما برای تعیین آیکون‌های سایت (هم آیکون‌های favicon و هم آیکون‌های صفحه اصلی و برنامه‌های دستگاه‌های همراه) نیز به کار می‌رود.                                                                       |
| `<meta>`                | نمایانگر metadataهایی است که نمی‌توان با دیگر المان‌های مرتبط با metadata در HTML (مانند `<base>`، `<link>`، `<script>`، `<style>` و `<title>`) نمایش داد.                                                                                                                                                      |
| `<style>`               | حاوی اطلاعات سبک‌دهی (CSS) برای یک سند یا بخشی از آن است. این المان شامل CSS است که به محتوای سند حاوی آن اعمال می‌شود.                                                                                                                                                                                         |
| `<title>`               | عنوان سند را تعیین می‌کند که در نوار عنوان (title bar) مرورگر یا زبانه (tab) صفحه نمایش داده می‌شود. فقط شامل متن است؛ تگ‌های HTML درون آن، اگر وجود داشته باشند، به‌عنوان متن ساده در نظر گرفته می‌شوند.                                                                                                 |

## ریشه بخش‌بندی (Sectioning root)

| المان     | توضیحات                                                                     |
| --------- | ------------------------------------------------------------------------------------------------------------------------------------------- |
| `<body>`  | محتوای یک سند HTML را نمایش می‌دهد. فقط یک عدد از این المان می‌تواند در سند وجود داشته باشد. |

## بخش‌بندی محتوا (Content sectioning)

المان‌های بخش‌بندی محتوا به شما کمک می‌کنند تا محتوای سند را به بخش‌های منطقی تقسیم کنید. از این المان‌ها برای ایجاد یک طرح کلی (outline) از محتوای صفحه استفاده کنید، از جمله ناوبری هدر و فوتر (header and footer navigation) و همچنین المان‌های heading (عنوان) برای شناسایی بخش‌های مختلف محتوا.

| Element                                                                                                                                                                                                                                                                                                                                                                                                                | توضیحات                                                                                                                                                                                                                                                                                                                                                            |
| ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| {{HTMLElement("address")}}                                                                                                                                                                                                                                                                                                                                                                                             | نشان می‌دهد که محتوای درون آن اطلاعات تماس برای یک شخص، افراد یا یک سازمان را ارائه می‌دهد.                                                                                                                                                                                                                                                                        |
| {{HTMLElement("article")}}                                                                                                                                                                                                                                                                                                                                                                                             | یک قطعه محتوای مستقل در یک سند، صفحه، برنامه یا سایت را نشان می‌دهد که قابلیت توزیع یا استفاده مجدد جداگانه (مثلاً در syndication) را دارد. مثال‌ها شامل یک پست انجمن، مقاله مجله یا روزنامه، پست وبلاگ، کارت محصول، نظر کاربر، یک ویجت یا گجت تعاملی، یا هر آیتم محتوای مستقل دیگر است.                                                                               |
| {{HTMLElement("aside")}}                                                                                                                                                                                                                                                                                                                                                                                               | بخشی از سند را نشان می‌دهد که محتوای آن فقط به‌طور غیرمستقیم با محتوای اصلی سند مرتبط است. این بخش‌ها اغلب به‌عنوان نوار کناری یا جعبه نکته‌برجسته نمایش داده می‌شوند.                                                                                                                                                                                            |
| {{HTMLElement("footer")}}                                                                                                                                                                                                                                                                                                                                                                                              | یک پاورقی برای نزدیک‌ترین عنصر جداساز محتوا (sectioning content) یا ریشه جداساز (sectioning root) خود را نشان می‌دهد. یک `<footer>` معمولاً شامل اطلاعاتی درباره نویسنده بخش، داده‌های حق‌نشر (copyright) یا پیوندهایی به اسناد مرتبط است.                                                                                                                        |
| {{HTMLElement("header")}}                                                                                                                                                                                                                                                                                                                                                                                              | محتوای مقدماتی را نشان می‌دهد، معمولاً گروهی از راهنماهای مقدماتی یا ناوبری. می‌تواند شامل برخی عناصر عنوان (heading) باشد، همچنین یک لوگو، فرم جستجو، نام نویسنده و عناصر دیگر.                                                                                                                                                                                  |
| [`<h1>`](/en-US/docs/Web/HTML/Reference/Elements/Heading_Elements), [`<h2>`](/en-US/docs/Web/HTML/Reference/Elements/Heading_Elements), [`<h3>`](/en-US/docs/Web/HTML/Reference/Elements/Heading_Elements), [`<h4>`](/en-US/docs/Web/HTML/Reference/Elements/Heading_Elements), [`<h5>`](/en-US/docs/Web/HTML/Reference/Elements/Heading_Elements), [`<h6>`](/en-US/docs/Web/HTML/Reference/Elements/Heading_Elements) | شش سطح از عنوان‌های بخش‌بندی را نشان می‌دهند. `<h1>` بالاترین سطح بخش و `<h6>` پایین‌ترین سطح است.                                                                                                                                                                                                                                                                |
| {{HTMLElement("hgroup")}}                                                                                                                                                                                                                                                                                                                                                                                              | یک عنوان را به همراه محتوای ثانویه مانند زیرعنوان، عنوان جایگزین، یا یک شعار (tagline) گروه‌بندی می‌کند.                                                                                                                                                                                                                                                          |
| {{HTMLElement("main")}}                                                                                                                                                                                                                                                                                                                                                                                                | محتوای غالب بدنه یک سند را نشان می‌دهد. ناحیه محتوای اصلی شامل محتوایی است که مستقیماً به موضوع مرکزی سند مرتبط است یا آن را بسط می‌دهد، یا عملکرد اصلی یک برنامه را نشان می‌دهد.                                                                                                                                                                                |
| {{HTMLElement("nav")}}                                                                                                                                                                                                                                                                                                                                                                                                 | بخشی از یک صفحه را نشان می‌دهد که هدف آن ارائه لینک‌های ناوبری است، چه درون سند فعلی و چه به اسناد دیگر. نمونه‌های رایج بخش‌های ناوبری عبارتند از منوها، فهرست مطالب و ایندکس‌ها.                                                                                                                                                                                 |
| {{HTMLElement("section")}}                                                                                                                                                                                                                                                                                                                                                                                             | یک بخش عمومی و مستقل از سند را نشان می‌دهد که عنصر معنایی خاص‌تری برای نمایش آن وجود ندارد. بخش‌ها معمولاً باید یک عنوان داشته باشند، به جز موارد استثنا.                                                                                                                                                                                                          |
| {{HTMLElement("search")}}                                                                                                                                                                                                                                                                                                                                                                                              | بخشی را نشان می‌دهد که شامل مجموعه‌ای از کنترل‌های فرم یا محتوای دیگر مرتبط با انجام عملیات جستجو یا فیلتر است.                                                                                                                                                                                                                                                  |

برای سازمان‌دهی بلوک‌ها یا بخش‌های محتوایی که بین تگ شروع `<body>` و تگ پایان `</body>` قرار می‌گیرند، از المان‌های محتوای متنی HTML استفاده کنید. این المان‌ها برای دسترس‌پذیری (accessibility) و سئو (SEO) مهم هستند و هدف یا ساختار آن محتوا را مشخص می‌کنند.

| عنصر | توضیحات |
| --- | --- |
| `blockquote` | نشان‌دهندهٔ نقل‌قول طولانی است. معمولاً به صورت بصری با تورفتگی (indentation) نمایش داده می‌شود. آدرس منبع نقل‌قول را می‌توان با attribute «cite» مشخص کرد و نمایش متنی منبع را با عنصر `cite` ارائه داد. |
| `dd` | توضیح، تعریف یا مقدار عبارت قبلی (عنصر `dt`) را در یک لیست توضیحات (عنصر `dl`) فراهم می‌کند. |
| `div` | کانتینر عمومی برای محتوای جریانی (flow content) است. تا زمانی که با استفاده از CSS استایل نشود، تأثیری روی محتوا یا طرح‌بندی ندارد (مثلاً استایل مستقیماً به آن اعمال شود، یا مدل طرح‌بندی‌ای مثل فلکس‌باکس (flexbox) روی عنصر والد آن اعمال شود). |
| `dl` | یک لیست توضیحات را نشان می‌دهد. این عنصر شامل فهرستی از گروه‌های اصطلاحات (با عنصر `dt`) و توضیحات (با عناصر `dd`) است. کاربردهای رایج آن برای ساخت واژه‌نامه یا نمایش متادیتا (فهرستی از جفت‌های کلید-مقدار) است. |
| `dt` | یک اصطلاح را در لیست توضیحات یا تعریف مشخص می‌کند و بنابراین باید داخل عنصر `dl` استفاده شود. معمولاً یک عنصر `dd` بعد از آن می‌آید؛ با این حال، چند عنصر متوالی `dt` نشان می‌دهند که همهٔ آن اصطلاحات توسط عنصر `dd` بلافاصله بعدی تعریف می‌شوند. |
| `figcaption` | عنوان یا شرحی را نشان می‌دهد که بقیهٔ محتویات عنصر والد (`figure`) را توصیف می‌کند. |
| `figure` | محتوای خودکفا را نشان می‌دهد که می‌تواند یک عنوان اختیاری داشته باشد؛ این عنوان با عنصر `figcaption` مشخص می‌شود. عنصر `figure`، عنوانش و محتویاتش به صورت یک واحد یکپارچه در نظر گرفته می‌شوند. |
| `hr` | یک شکست موضوعی بین عناصر در سطح پاراگراف را نشان می‌دهد؛ برای مثال، تغییر صحنه در یک داستان یا تغییر موضوع در یک بخش. |
| `li` | یک آیتم در یک لیست را نشان می‌دهد. باید داخل عنصر والد قرار بگیرد: لیست مرتب (`ol`)، لیست نامرتب (`ul`) یا منو (`menu`). در منوها و لیست‌های نامرتب، آیتم‌ها معمولاً با نقطه (bullet) نمایش داده می‌شوند. در لیست‌های مرتب، معمولاً با شمارنده‌ای صعودی در سمت چپ، مثل عدد یا حرف، نمایش داده می‌شوند. |
| `menu` | جایگزین معنایی برای `ul` است، اما مرورگرها (و درخت دسترس‌پذیری) آن را دقیقاً مثل `ul` رفتار می‌کنند. این عنصر یک لیست نامرتب از آیتم‌ها را نشان می‌دهد (که با عناصر `li` نمایش داده می‌شوند). |
| `ol` | یک لیست مرتب از آیتم‌ها را نشان می‌دهد — معمولاً به صورت لیست شماره‌دار نمایش داده می‌شود. |
| `p` | یک پاراگراف را نشان می‌دهد. پاراگراف‌ها معمولاً در رسانه‌های بصری به صورت بلوک‌هایی از متن نمایش داده می‌شوند که از بلوک‌های مجاور با خطوط خالی و/یا تورفتگی خط اول جدا شده‌اند، اما پاراگراف‌های HTML می‌توانند هر گروه ساختاری از محتوای مرتبط باشند، مثل تصاویر یا فیلدهای فرم. |
| `pre` | متن از پیش قالب‌بندی‌شده را نشان می‌دهد که باید دقیقاً همان‌طور که در فایل HTML نوشته شده ارائه شود. این متن معمولاً با فونت ناهم‌عرض (non-proportional) یا [یکدست (monospaced)](https://en.wikipedia.org/wiki/Monospaced_font) نمایش داده می‌شود. فاصله‌های خالی داخل این عنصر دقیقاً به همان شکلی که نوشته شده‌اند نمایش داده می‌شوند. |
| `ul` | یک لیست نامرتب از آیتم‌ها را نشان می‌دهد که معمولاً به صورت فهرست نقطه‌ای نمایش داده می‌شود. |

## Inline text semantics

از inline text semantics در HTML برای تعریف معنا، ساختار یا سبک یک کلمه، خط یا هر قطعه متن دلخواه استفاده کنید.

| Element | توضیحات |
| --- | --- |
| `<a>` | به همراه attribute مخصوص `href`، یک لینک (hyperlink) به صفحات وب، فایل‌ها، آدرس‌های ایمیل، موقعیت‌های داخل صفحهٔ فعلی یا هر چیز دیگری که یک URL بتواند به آن اشاره کند، می‌سازد. |
| `<abbr>` | یک abbreviation (کوته‌نوشت) یا acronym (سرنام) را نمایش می‌دهد. |
| `<b>` | برای جلب توجه خواننده به محتوای element به کار می‌رود؛ محتوایی که به خودی خود اهمیت ویژه‌ای ندارد. این عنصر قبلاً با نام Boldface (متن ضخیم) شناخته می‌شد و همچنان بیشتر browserها متن را به صورت bold نمایش می‌دهند. با این حال، نباید از `<b>` برای استایل دادن به متن یا نشان دادن اهمیت استفاده کنید. اگر می‌خواهید متن bold بسازید، از property مربوط به CSS یعنی `font-weight` استفاده کنید. و اگر می‌خواهید نشان دهید یک element اهمیت ویژه‌ای دارد، از عنصر `<strong>` استفاده کنید. |
| `<bdi>` | به الگوریتم دوجهته (bidirectional) مرورگر می‌گوید که متن داخل خود را جدا از متن اطرافش در نظر بگیرد. این کار مخصوصاً وقتی مفید است که یک وب‌سایت متنی را به صورت پویا (dynamically) درج می‌کند و از جهت (directionality) متن درج‌شده اطلاعی ندارد. |
| `<bdo>` | جهت فعلی متن را override می‌کند، به طوری که متن داخل آن در جهتی متفاوت render می‌شود. |
| `<br>` | یک خط‌شکن (line break) در متن ایجاد می‌کند (carriage-return). برای نوشتن شعر یا آدرس مفید است، جایی که تقسیم خطوط اهمیت دارد. |
| `<cite>` | برای نشانه‌گذاری (mark up) عنوان یک اثر خلاقانه استفاده می‌شود. ارجاع ممکن است طبق قراردادهای مناسب context مربوط به فرادادهٔ (metadata) نقل‌قول، به صورت خلاصه‌شده باشد. |
| `<code>` | محتوای خود را با استایلی نمایش می‌دهد که نشان دهد متن، یک قطعهٔ کوتاه از کد کامپیوتر است. به صورت پیش‌فرض، متن محتوا با فونت monospace پیش‌فرض user agent نمایش داده می‌شود. |
| `<data>` | یک قطعه محتوای مشخص را به ترجمه‌ای قابل‌خواندن توسط ماشین (machine-readable) پیوند می‌دهد. اگر محتوا مربوط به زمان یا تاریخ است، باید از عنصر `<time>` استفاده شود. |
| `<dfn>` | برای نشان دادن اصطلاحی که در context یک عبارت یا جملهٔ تعریفی تعریف می‌شود، استفاده می‌شود. عنصر ancestor یعنی `<p>`، جفت `<dt>`/`<dd>` یا نزدیک‌ترین ancestor بخش از عنصر `<dfn>` به عنوان تعریف اصطلاح در نظر گرفته می‌شود. |
| `<em>` | متنی را که تأکید (stress emphasis) دارد مشخص می‌کند. عنصر `<em>` می‌تواند تو در تو (nested) باشد و هر سطح تودرتو نشان‌دهندهٔ درجهٔ بیشتری از تأکید است. |
| `<i>` | بخشی از متن را نشان می‌دهد که به دلایلی از متن عادی جدا شده است؛ مانند متن اصطلاحی (idiomatic)، اصطلاحات فنی و نام‌های طبقه‌بندی (taxonomical). از نظر تاریخی، این موارد با حروف italic نمایش داده می‌شدند و این همان منشأ نام‌گذاری `<i>` برای این عنصر است. |
| `<kbd>` | یک بخش از متن خطی (inline) را نشان می‌دهد که ورودی کاربر را از صفحه‌کلید، ورودی صوتی یا هر دستگاه ورودی متن دیگری مشخص می‌کند. طبق قرارداد، user agent به صورت پیش‌فرض محتوای عنصر `<kbd>` را با فونت monospace پیش‌فرض خود render می‌کند؛ هرچند استاندارد HTML این الزام را تعیین نکرده است. |
| `<mark>` | متنی را نشان می‌دهد که به دلیل مرتبط بودن بخش علامت‌گذاری‌شده در context اطراف، برای ارجاع یا یادداشت‌گذاری علامت‌گذاری یا هایلایت شده است. |
| `<q>` | نشان می‌دهد که متن داخل آن یک نقل‌قول کوتاه خطی (inline) است. بیشتر browserهای مدرن این را با قرار دادن متن داخل علامت نقل‌قول پیاده‌سازی می‌کنند. این عنصر برای نقل‌قول‌های کوتاهی است که به break پاراگراف نیاز ندارند؛ برای نقل‌قول‌های طولانی از عنصر `<blockquote>` استفاده کنید. |
| `<rp>` | برای ارائه پرانتزهای جایگزین (fall-back) در browserهایی استفاده می‌شود که نمایش ruby annotation را با استفاده از عنصر `<ruby>` پشتیبانی نمی‌کنند. یک عنصر `<rp>` باید هر یک از پرانتزهای باز و بسته‌ای را که دور عنصر `<rt>` حاوی متن annotation قرار می‌گیرند، محصور کند. |
| `<rt>` | مؤلفهٔ متن ruby یک ruby annotation را مشخص می‌کند که برای ارائه اطلاعات تلفظ، ترجمه یا آوانویسی (transliteration) در تایپوگرافی شرق آسیا استفاده می‌شود. عنصر `<rt>` همیشه باید داخل یک عنصر `<ruby>` قرار گیرد. |
| `<ruby>` | نشانه‌گذاری‌های کوچکی را نشان می‌دهد که بالای متن پایه، پایین آن یا کنار آن render می‌شوند و معمولاً برای نمایش تلفظ نویسه‌های (characters) شرق آسیا استفاده می‌شوند. می‌توان از آن برای annotate کردن انواع دیگر متن نیز استفاده کرد، اما این کاربرد رایج‌تر نیست. |
| `<s>` | متن را با خط خوردگی (strikethrough) یا خط روی آن render می‌کند. از عنصر `<s>` برای نشان دادن چیزهایی استفاده کنید که دیگر مرتبط یا دقیق نیستند. با این حال، `<s>` برای نشان دادن ویرایش‌های سند مناسب نیست؛ برای این منظور، بسته به مورد از عناصر `<del>` و `<ins>` استفاده کنید. |
| `<samp>` | برای محصور کردن متن خطی استفاده می‌شود که خروجی نمونه (یا نقل‌قول‌شده) از یک برنامه کامپیوتری را نشان می‌دهد. محتوای آن معمولاً با فونت monospace پیش‌فرض مرورگر (مانند Courier یا Lucida Console) render می‌شود. |
| `<small>` | نظرات کناری و چاپ کوچک (small print)، مانند متن کپی‌رایت و حقوقی را نشان می‌دهد، مستقل از ظاهر استایل‌شدهٔ آن. به صورت پیش‌فرض، متن داخل آن را یک اندازه فونت کوچک‌تر render می‌کند، مثلاً از `small` به `x-small`. |
| `<span>` | یک ظرف (container) خطی عمومی برای محتوای متنی (phrasing content) است که ذاتاً چیز خاصی را نشان نمی‌دهد. می‌توان از آن برای گروه‌بندی عناصر به منظور استایل‌دادن (با استفاده از attributeهای `class` یا `id`) یا به دلیل اشتراک در مقادیر attributeهایی مثل `lang` استفاده کرد. فقط زمانی باید از آن استفاده شود که هیچ عنصر معنایی (semantic) دیگری مناسب نباشد. `<span>` بسیار شبیه عنصر div است، اما div یک عنصر block-level است، در حالی که `<span>` یک عنصر inline-level است. |
| `<strong>` | نشان می‌دهد که محتوای آن اهمیت، جدیت یا فوریت زیادی دارد. مرورگرها معمولاً محتوا را به صورت bold نمایش می‌دهند. |
| `<sub>` | متن خطی را مشخص می‌کند که صرفاً به دلایل تایپوگرافی باید به صورت زیرنویس (subscript) نمایش داده شود. زیرنویس‌ها معمولاً با baseline پایین‌تر و متن کوچک‌تر render می‌شوند. |
| `<sup>` | متن خطی را مشخص می‌کند که صرفاً به دلایل تایپوگرافی باید به صورت بالانویس (superscript) نمایش داده شود. بالانویس‌ها معمولاً با baseline بالاتر و متن کوچک‌تر render می‌شوند. |
| `<time>` | یک بازهٔ زمانی مشخص را نشان می‌دهد. می‌تواند شامل attribute `datetime` باشد تا تاریخ‌ها را به فرمت قابل‌خواندن توسط ماشین تبدیل کند و نتایج بهتری در موتورهای جستجو یا ویژگی‌های سفارشی مانند یادآورها فراهم کند. |
| `<u>` | بخشی از متن خطی را نشان می‌دهد که باید به گونه‌ای render شود که مشخص کند یک annotation غیرمتنی دارد. به صورت پیش‌فرض، این حالت به صورت یک خط زیرین (underline) ممتد نمایش داده می‌شود، اما می‌توان آن را با CSS تغییر داد. |
| `<var>` | نام یک متغیر (variable) را در یک عبارت ریاضی یا context برنامه‌نویسی نشان می‌دهد. معمولاً با نسخهٔ italic فونت فعلی نمایش داده می‌شود، اگرچه این رفتار به browser بستگی دارد. |
| `<wbr>` | یک فرصت شکستن کلمه (word break) را نشان می‌دهد—موقعیتی در متن که مرورگر می‌تواند به صورت اختیاری خط را در آن بشکند، در حالی که قوانین خط‌شکنی آن به طور عادی در آن موقعیت شکستی ایجاد نمی‌کنند. |

## تصویر و چندرسانه‌ای

HTML از منابع چندرسانه‌ای مختلف مانند تصویر، صدا و ویدیو پشتیبانی می‌کند.

| Element                  | توضیحات                                                                                                                                                                                                                                                                                           |
| ------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| {{HTMLElement("area")}}  | یک ناحیه داخل image map (نقشه تصویری) تعریف می‌کند که نواحی قابل کلیک از پیش تعیین شده دارد. یک _نقشه تصویری_ به نواحی هندسی روی تصویر اجازه می‌دهد تا با {{Glossary("Hyperlink", "hyperlink")}} (پیوند) مرتبط شوند.                                                                             |
| {{HTMLElement("audio")}} | برای جاسازی محتوای صوتی در صفحه استفاده می‌شود. می‌تواند یک یا چند منبع صوتی داشته باشد که با attribute `src` یا عنصر source مشخص می‌شوند؛ مرورگر مناسب‌ترین گزینه را انتخاب می‌کند. همچنین می‌تواند مقصد محتوای پخش زنده (stream) باشد با استفاده از {{domxref("MediaStream")}}.                     |
| {{HTMLElement("img")}}   | یک تصویر را درون سند جاسازی می‌کند.                                                                                                                                                                                                                                                              |
| {{HTMLElement("map")}}   | همراه با عناصر {{HTMLElement("area")}} برای تعریف image map (ناحیه لینک قابل کلیک) استفاده می‌شود.                                                                                                                                                                                               |
| {{HTMLElement("track")}} | به عنوان فرزند عناصر رسانه (audio و video) استفاده می‌شود. اجازه می‌دهد زیرنویس‌های زمانی (timed text tracks) یا داده‌های مبتنی بر زمان را مشخص کنید، مثلاً برای مدیریت خودکار زیرنویس‌ها. این tracks در قالب [WebVTT](/en-US/docs/Web/API/WebVTT_API) (`.vtt` files) هستند—Web Video Text Tracks. |
| {{HTMLElement("video")}} | یک پخش‌کننده رسانه که از پخش ویدیو پشتیبانی می‌کند را درون سند جاسازی می‌کند. همچنین می‌توانید از `<video>` برای محتوای صوتی استفاده کنید، اما عنصر audio تجربه کاربری مناسب‌تری ارائه می‌دهد.                                                                                                       |

## محتوای جاسازی‌شده

علاوه بر محتوای چندرسانه‌ای معمولی، HTML می‌تواند انواع دیگری از محتوا را نیز شامل شود، حتی اگر تعامل با آن‌ها همیشه آسان نباشد.

| عنصر | توضیحات |
| --- | --- |
| `<embed>` | محتوای خارجی را در نقطه مشخص‌شده در سند جاسازی می‌کند. این محتوا توسط یک برنامه خارجی یا منبع دیگری از محتوای تعاملی، مانند افزونه مرورگر (browser plug-in)، ارائه می‌شود. |
| `<fencedframe>` | یک context مرور تودرتو را نمایانگری می‌کند؛ مانند `<iframe>` اما با ویژگی‌های حریم خصوصی بومی بیشتری که به صورت داخلی در آن تعبیه شده است. |
| `<iframe>` | یک context مرور تودرتو را نمایش می‌دهد و صفحه HTML دیگری را در صفحه فعلی جاسازی می‌کند. |
| `<object>` | یک منبع خارجی را نمایانگری می‌کند که می‌توان آن را به عنوان تصویر، یک context مرور تودرتو، یا منبعی که باید توسط یک افزونه مدیریت شود در نظر گرفت. |
| `<picture>` | شامل صفر یا چند عنصر `<source>` و یک عنصر `<img>` است تا نسخه‌های جایگزینی از یک تصویر را برای سناریوهای مختلف نمایش یا دستگاه‌ها ارائه دهد. |
| `<source>` | منابع رسانه‌ای متعددی را برای عنصر `picture`، عنصر `audio` یا عنصر `video` مشخص می‌کند. این یک عنصر void است؛ یعنی محتوایی ندارد و تگ پایانی ندارد. معمولاً برای ارائه همان محتوای رسانه‌ای در چند قالب فایل استفاده می‌شود تا با توجه به پشتیبانی متفاوت مرورگرها از [فرمت‌های فایل تصویری](/en-US/docs/Web/Media/Guides/Formats/Image_types) و [فرمت‌های فایل رسانه‌ای](/en-US/docs/Web/Media/Guides/Formats)، سازگاری گسترده‌ای با مرورگرهای مختلف فراهم شود. |

## SVG و MathML

می‌توانید محتوای [SVG](/en-US/docs/Web/SVG) و [MathML](/en-US/docs/Web/MathML) را مستقیماً در اسناد HTML جاسازی کنید؛ با استفاده از المان‌های `<svg>` و `<math>`.

| المان | توضیحات |
| --- | --- |
| `<svg>` | ظرفی که یک سیستم مختصات و [viewport](/en-US/docs/Web/SVG/Reference/Attribute/viewBox) جدید تعریف می‌کند. به عنوان بیرونی‌ترین المان در اسناد SVG استفاده می‌شود، اما می‌توان از آن برای جاسازی یک قطعه SVG داخل سند SVG یا HTML نیز استفاده کرد. |
| `<math>` | المان سطح بالا در MathML است. هر نمونه معتبر MathML باید درون آن قرار گیرد. علاوه بر این، نباید یک المان `<math>` دوم داخل `<math>` دیگر قرار دهید، اما می‌توانید تعداد دلخواهی از المان‌های فرزند دیگر در آن داشته باشید. |

## اسکریپت‌نویسی

برای ایجاد محتوای پویا و اپلیکیشن‌های وب، HTML از زبان‌های اسکریپت‌نویسی پشتیبانی می‌کند؛ مهم‌ترین آنها جاوااسکریپت است. برخی المان‌ها این قابلیت را فراهم می‌کنند.

| المان | توضیحات |
| --- | --- |
| `<canvas>` | المان ظرفی برای استفاده با [Canvas scripting API](/en-US/docs/Web/API/Canvas_API) یا [WebGL API](/en-US/docs/Web/API/WebGL_API) به منظور رسم گرافیک و انیمیشن. |
| `<noscript>` | قسمتی از HTML را تعریف می‌کند که اگر نوع اسکریپت صفحه پشتیبانی نشود یا اسکریپت‌نویسی در مرورگر خاموش باشد، درج می‌شود. |
| `<script>` | برای جاسازی کد یا داده‌های قابل اجرا استفاده می‌شود؛ معمولاً برای جاسازی یا ارجاع به کد جاوااسکریپت به کار می‌رود. المان `<script>` می‌تواند با زبان‌های دیگر مانند زبان برنامه‌نویسی شیدر GLSL در WebGL و [JSON](/en-US/docs/Glossary/JSON) نیز استفاده شود. |

## مشخص کردن ویرایش‌ها

این المان‌ها به شما امکان می‌دهند نشان دهید که بخش‌های خاصی از متن تغییر کرده‌اند.

| Element                | توضیحات                                                                                                                                                                                                                                                                                                                    |
| ---------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| {{HTMLElement("del")}} | نشان‌دهندهٔ متنی است که از سند حذف شده. می‌توان از آن مثلاً برای نمایش «تغییرات ردیابی شده» یا diff کد منبع استفاده کرد. عنصر `<ins>` کاربرد عکس دارد: مشخص کردن متنی که به سند اضافه شده.                                                                                                                              |
| {{HTMLElement("ins")}} | نشان‌دهندهٔ متنی است که به سند اضافه شده. برای نمایش متنی که حذف شده، می‌توانید از عنصر `<del>` استفاده کنید.                                                                                                                                                                                                            |

## محتوای جدول

از این عناصر برای ایجاد و مدیریت داده‌های جدولی استفاده می‌شود.

| Element                     | Description                                                                                                                                                                                                                                                                                                            |
| --------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| {{HTMLElement("caption")}}  | مشخص‌کنندهٔ شرح (caption) یا عنوان جدول.                                                                                                                                                                                                                                                                              |
| {{HTMLElement("col")}}      | یک یا چند ستون را در یک گروه ستونی که توسط عنصر والد (صریح یا ضمنی) {{HTMLElement("colgroup")}} نمایش داده می‌شود، تعریف می‌کند. عنصر `<col>` فقط به عنوان فرزند عنصر `<colgroup>` که ویژگی [`span`](/en-US/docs/Web/HTML/Reference/Elements/colgroup#span) ندارد معتبر است.                                                                 |
| {{HTMLElement("colgroup")}} | گروهی از ستون‌ها را درون جدول تعریف می‌کند.                                                                                                                                                                                                                                                                          |
| {{HTMLElement("table")}}    | داده‌های جدولی (tabular data) را نمایش می‌دهد — یعنی اطلاعاتی که در یک جدول دو بعدی شامل سطرها و ستون‌هایی از سلول‌های حاوی داده ارائه می‌شود.                                                                                                                                                                      |
| {{HTMLElement("tbody")}}    | مجموعه‌ای از سطرهای جدول (عناصر {{HTMLElement("tr")}}) را در بر می‌گیرد و نشان می‌دهد که بدنهٔ داده‌های اصلی جدول را تشکیل می‌دهند.                                                                                                                                                                                |
| {{HTMLElement("td")}}       | فرزند عنصر {{HTMLElement("tr")}} است و یک سلول از جدول که حاوی داده است را تعریف می‌کند.                                                                                                                                                                                                                             |
| {{HTMLElement("tfoot")}}    | مجموعه‌ای از سطرهای جدول (عناصر {{HTMLElement("tr")}}) را در بر می‌گیرد و نشان می‌دهد که پای جدول با اطلاعاتی دربارهٔ ستون‌های جدول را تشکیل می‌دهند. این معمولاً خلاصه‌ای از ستون‌ها است، مثلاً جمع اعداد داده شده در یک ستون.                                                                                      |
| {{HTMLElement("th")}}       | فرزند عنصر {{HTMLElement("tr")}} است و یک سلول را به عنوان سربرگ (header) گروهی از سلول‌های جدول تعریف می‌کند. ماهیت این گروه می‌تواند به طور صریح توسط ویژگی‌های [`scope`](/en-US/docs/Web/HTML/Reference/Elements/th#scope) و [`headers`](/en-US/docs/Web/HTML/Reference/Elements/th#headers) مشخص شود.                                 |
| {{HTMLElement("thead")}}    | مجموعه‌ای از سطرهای جدول (عناصر {{HTMLElement("tr")}}) را در بر می‌گیرد و نشان می‌دهد که سر جدول با اطلاعاتی دربارهٔ ستون‌های جدول را تشکیل می‌دهند. این معمولاً به صورت سربرگ‌های ستون (عناصر {{HTMLElement("th")}}) است.                                                                                         |
| {{HTMLElement("tr")}}       | یک سطر از سلول‌ها در جدول را تعریف می‌کند. سلول‌های سطر می‌توانند با ترکیبی از عناصر {{HTMLElement("td")}} (سلول داده) و {{HTMLElement("th")}} (سلول سربرگ) ایجاد شوند.                                                                                                                                              |

## فرم‌ها

HTML چندین element را فراهم می‌کند که با کنار هم قرار دادن آن‌ها می‌توان فرم‌هایی ساخت تا کاربر آن‌ها را پر کرده و به وب‌سایت یا برنامه ارسال کند. برای اطلاعات بیشتر به [راهنمای فرم‌های HTML](/en-US/docs/Learn_web_development/Extensions/Forms) مراجعه کنید.

| عنصر                           | توضیحات                                                                                                                                                                                                                                                                                                                                                                                                                                                 |
| ------------------------------ | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `<button>`                     | یک عنصر تعاملی که کاربر با ماوس، صفحه‌کلید، انگشت، فرمان صوتی یا فناوری کمکی دیگر آن را فعال می‌کند. پس از فعال‌سازی، عملی مانند ارسال فرم یا باز کردن یک dialog انجام می‌دهد.                                                                                                                                                                                                                                                                            |
| `<datalist>`                   | شامل مجموعه‌ای از عناصر `<option>` است که گزینه‌های مجاز یا پیشنهادی برای انتخاب در سایر کنترل‌ها را مشخص می‌کند.                                                                                                                                                                                                                                                                                                                                       |
| `<fieldset>`                   | برای گروه‌بندی چندین کنترل به همراه برچسب‌هایشان (`<label>`) در یک فرم وب استفاده می‌شود.                                                                                                                                                                                                                                                                                                                                                               |
| `<form>`                       | بخشی از سند را نشان می‌دهد که شامل کنترل‌های تعاملی برای ارسال اطلاعات است.                                                                                                                                                                                                                                                                                                                                                                             |
| `<input>`                      | برای ایجاد کنترل‌های تعاملی در فرم‌های وب جهت دریافت داده از کاربر استفاده می‌شود. بسته به دستگاه و user agent، انواع مختلفی از داده‌های ورودی و ویجت‌های کنترلی در دسترس است. عنصر `<input>` به دلیل تنوع بالای ترکیب نوع‌های ورودی و attributeها، یکی از قدرتمندترین و پیچیده‌ترین عناصر HTML است.                                                                                                                                                      |
| `<label>`                      | یک برچسب (caption) برای یک آیتم در رابط کاربری را نشان می‌دهد.                                                                                                                                                                                                                                                                                                                                                                                          |
| `<legend>`                     | یک برچسب برای محتوای عنصر والد `<fieldset>` خود را نشان می‌دهد.                                                                                                                                                                                                                                                                                                                                                                                         |
| `<meter>`                      | یا یک مقدار عددی در یک بازه مشخص یا یک مقدار کسری را نشان می‌دهد.                                                                                                                                                                                                                                                                                                                                                                                       |
| `<optgroup>`                   | گروه‌بندی گزینه‌ها را درون یک عنصر `<select>` ایجاد می‌کند.                                                                                                                                                                                                                                                                                                                                                                                             |
| `<option>`                     | برای تعریف یک آیتم درون عناصر `<select>`، `<optgroup>` یا `<datalist>` استفاده می‌شود. بنابراین `<option>` می‌تواند آیتم‌های منو را در پاپ‌آپ‌ها و سایر لیست‌های آیتم‌های یک سند HTML نمایش دهد.                                                                                                                                                                                                                                                         |
| `<output>`                     | یک عنصر محفظه‌ای که سایت یا برنامه می‌تواند نتیجه یک محاسبه یا خروجی یک اقدام کاربر را درون آن قرار دهد.                                                                                                                                                                                                                                                                                                                                                 |
| `<progress>`                   | یک نشانگر برای نمایش پیشرفت تکمیل یک کار را نشان می‌دهد که معمولاً به صورت نوار پیشرفت نمایش داده می‌شود.                                                                                                                                                                                                                                                                                                                                               |
| `<select>`                     | یک کنترل که منویی از گزینه‌ها را ارائه می‌دهد.                                                                                                                                                                                                                                                                                                                                                                                                          |
| `<selectedcontent>`            | محتوای `<option>` انتخاب‌شده را درون یک `<select>` بسته نمایش می‌دهد.                                                                                                                                                                                                                                                                                                                                                                                   |
| `<textarea>`                   | یک کنترل ویرایش متن چندخطی (plain-text) را نشان می‌دهد. زمانی مفید است که بخواهید کاربران مقدار قابل توجهی متن آزاد وارد کنند، مثلاً نظر در یک فرم بازبینی یا بازخورد.                                                                                                                                                                                                                                                                                   |

## عناصر تعاملی

HTML عناصری را ارائه می‌دهد که به ساخت رابط‌های کاربری تعاملی کمک می‌کنند.

| عنصر       | توضیحات                                                                                                                                                      |
| ---------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `<details>` | یک ویجت بازشو ایجاد می‌کند که اطلاعات فقط زمانی نمایش داده می‌شوند که ویجت در حالت "باز" قرار گیرد. باید یک خلاصه یا برچسب با استفاده از عنصر `<summary>` ارائه شود. |
| `<dialog>` | یک کادر گفتگو یا یک مؤلفه تعاملی دیگر را نمایش می‌دهد؛ مانند هشدار قابل بستن، ابزار بازرسی یا زیرپنجره.                                                       |
| `<geolocation>` | یک کنترل تعاملی ایجاد می‌کند تا کاربر بتواند داده‌های موقعیت جغرافیایی خود را با صفحه به اشتراک بگذارد. (تجربی)                                              |
| `<summary>` | یک خلاصه، عنوان یا افسانه برای جعبه بازشوی عنصر details مشخص می‌کند. کلیک روی `<summary>` وضعیت باز یا بسته شدن عنصر والد `<details>` را تغییر می‌دهد.        |

## کامپوننت‌های وب (Web Components)

کامپوننت‌های وب فناوری مرتبط با HTML هستند که امکان ساخت و استفاده از عناصر سفارشی را مانند HTML معمولی فراهم می‌کنند. همچنین می‌توانید نسخه‌های سفارشی از عناصر استاندارد HTML ایجاد کنید.

| عنصر         | توضیحات                                                                                                                                                                              |
| ------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `<slot>`      | بخشی از مجموعه فناوری [کامپوننت‌های وب](/en-US/docs/Web/API/Web_components) است. این عنصر یک جای‌گیر (placeholder) درون یک کامپوننت وب است که می‌توانید آن را با نشانه‌گذاری خود پر کنید و به این ترتیب درخت‌های DOM جداگانه ایجاد کرده و آن‌ها را با هم ارائه دهید. |
| `<template>`  | مکانیزمی برای نگهداری HTML که هنگام بارگذاری صفحه بلافاصله رندر نمی‌شود، اما می‌تواند بعداً در زمان اجرا با استفاده از JavaScript نمونه‌سازی شود.                                    |

## عناصر منسوخ و قدیمی

> **هشدار:** این‌ها عناصر قدیمی HTML هستند که منسوخ (deprecated) شده‌اند و نباید استفاده شوند. **هرگز نباید از آن‌ها در پروژه‌های جدید استفاده کنید و در پروژه‌های قدیمی باید در سریع‌ترین زمان ممکن جایگزینشان کنید.** اینجا فقط برای تکمیل اطلاعات ذکر شده‌اند.

| عنصر | توضیحات |
| --- | --- |
| `<acronym>` | به نویسندگان این امکان را می‌دهد که دنباله‌ای از نویسه‌ها را که یک سرواژه (acronym) یا کوته‌نوشت (abbreviation) برای یک کلمه را تشکیل می‌دهند، به‌وضوح نشان دهند. |
| `<big>` | متن محصور را با اندازه فونتی یک سطح بزرگ‌تر از متن اطراف نمایش می‌دهد (مثلاً `medium` به `large` تبدیل می‌شود). اندازه به حداکثر اندازه فونت مجاز مرورگر محدود می‌شود. |
| `<center>` | محتوای block-level یا inline خود را به‌صورت افقی در مرکز عنصر والد قرار می‌دهد. |
| `<content>` | بخش منسوخ مجموعه فناوری‌های Web Components است؛ در داخل Shadow DOM به عنوان نقطه درج استفاده می‌شد و برای استفاده در HTML معمولی ساخته نشده بود. اکنون با عنصر `<slot>` جایگزین شده است که نقطه‌ای در DOM ایجاد می‌کند که می‌توان shadow DOM را در آن وارد کرد. به جای آن از `<slot>` استفاده کنید. |
| `<dir>` | ظرفی برای فهرست فایل‌ها و/یا پوشه‌ها، که احتمالاً عامل کاربر (user agent) سبک‌ها و آیکون‌ها را بر آن اعمال می‌کند. از این عنصر منسوخ استفاده نکنید؛ در عوض برای فهرست‌ها، از جمله فهرست فایل‌ها، از عنصر `<ul>` استفاده کنید. |
| `<font>` | اندازه، رنگ و نوع قلم را برای محتوای خود تعریف می‌کند. |
| `<frame>` | ناحیه خاصی را تعریف می‌کند که می‌توان یک سند HTML دیگر را در آن نمایش داد. یک frame باید داخل یک `<frameset>` استفاده شود. |
| `<frameset>` | برای نگهداری عناصر `<frame>` استفاده می‌شود. |
| `<image>` | پیشین بسیار قدیمی و کم‌پشتیبانی از عنصر `<img>` است. نباید استفاده شود. |
| `<marquee>` | برای قرار دادن ناحیه‌ای متحرک از متن استفاده می‌شود. می‌توانید با استفاده از ویژگی‌های (attributes) آن، رفتار متن را هنگام رسیدن به لبه‌های ناحیه محتوا کنترل کنید. |
| `<menuitem>` | دستوری را نشان می‌دهد که کاربر می‌تواند از طریق منوی بازشو (popup menu) آن را اجرا کند. این شامل منوهای زمینه (context menus) و همچنین منوهایی است که ممکن است به یک دکمه منو متصل باشند. |
| `<nobr>` | از شکسته شدن خودکار متن محتوا در چند خط جلوگیری می‌کند، که به‌طور بالقوه باعث می‌شود کاربر برای دیدن تمام عرض متن به‌صورت افقی اسکرول کند. |
| `<noembed>` | یک روش منسوخ و غیراستاندارد برای ارائه محتوای جایگزین یا «fallback» برای مرورگرهایی است که از عنصر embed یا نوع محتوای جاسازی‌شده مورد نظر نویسنده پشتیبانی نمی‌کنند. این عنصر در HTML 4.01 به بعد منسوخ شد؛ بهتر است محتوای جایگزین را بین تگ‌های باز و بسته عنصر `<object>` قرار دهید. |
| `<noframes>` | محتوایی را برای نمایش در مرورگرهایی فراهم می‌کند که از عنصر `<frame>` پشتیبانی نمی‌کنند (یا پشتیبانی آن را غیرفعال کرده‌اند). اگرچه بیشتر مرورگرهای رایج از frameها پشتیبانی می‌کنند، استثناهایی وجود دارد، از جمله برخی مرورگرهای خاص مانند برخی مرورگرهای موبایل و همچنین مرورگرهای متنی. |
| `<param>` | پارامترهایی را برای عنصر `<object>` تعریف می‌کند. |
| `<plaintext>` | تمام محتوای بعد از تگ شروع را به‌صورت متن خام (raw text) نمایش می‌دهد و هر HTML بعدی را نادیده می‌گیرد. تگ بسته ندارد، زیرا همه‌چیز بعد از آن متن خام محسوب می‌شود. |
| `<rb>` | برای مشخص کردن بخش متن پایه در یادداشت روبی (ruby annotation) استفاده می‌شود؛ یعنی متنی که در حال حاشیه‌نویسی است. یک عنصر `<rb>` باید هر بخش اتمیک جداگانه از متن پایه را در بر بگیرد. |
| `<rtc>` | حاشیه‌نویسی‌های معنایی نویسه‌ها را در یک روبی شامل عناصر `<rb>` که در داخل عنصر `<ruby>` استفاده می‌شوند، در بر می‌گیرد. عناصر `<rb>` می‌توانند هم حاشیه‌نویسی تلفظ (`<rt>`) و هم معنایی (`<rtc>`) داشته باشند. |
| `<shadow>` | بخش منسوخ مجموعه فناوری Web Components که برای استفاده به عنوان نقطه درج shadow DOM در نظر گرفته شده بود. اگر چندین shadow root را زیر یک shadow host ایجاد کرده‌اید، ممکن است از آن استفاده کرده باشید. به جای آن از `<slot>` استفاده کنید. |
| `<strike>` | یک خط روی متن می‌کشد (خط افقی). |
| `<tt>` | متنی درون‌خطی ایجاد می‌کند که با فونت monospace پیش‌فرض عامل کاربر (user agent) نمایش داده می‌شود. این عنصر برای رندر کردن متن به شکلی که در نمایشگرهای با عرض ثابت مانند تله‌تایپ، صفحه‌نمایش متنی یا چاپگر خطی نمایش داده می‌شد، ایجاد شده است. |
| `<xmp>` | متن بین تگ شروع و پایان را بدون تفسیر HTML در میان آن و با استفاده از فونت monospace نمایش می‌دهد. مشخصات HTML2 توصیه کرده بود که این عنصر به اندازه کافی عریض رندر شود تا ۸۰ نویسه در هر خط قرار بگیرد. |
