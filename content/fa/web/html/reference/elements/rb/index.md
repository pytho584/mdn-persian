## توضیحات

عنصر **`<rb>`** در HTML برای مشخص‌کردن بخش متن پایهٔ یک حاشیه‌نویسی {{HTMLElement("ruby")}} به کار می‌رود؛ یعنی همان متنی که حاشیه‌نویسی روی آن انجام می‌شود. هر بخش مجزای متن پایه باید با یک عنصر `<rb>` جداگانه محصور شود.

## ویژگی‌ها

این عنصر فقط شامل [ویژگی‌های سراسری](/en-US/docs/Web/HTML/Reference/Global_attributes) است.

## نکات استفاده

- حاشیه‌نویسی ruby برای نمایش تلفظ نویسه‌های شرق آسیا استفاده می‌شود، مثل فوریگانای ژاپنی یا بُپوموفوی تایوانی. عنصر `<rb>` هر بخش از متن پایهٔ ruby را جدا می‌کند.
- اگرچه `<rb>` یک عنصر تهی نیست، معمولاً در کد منبع فقط تگ شروع هر عنصر نوشته می‌شود تا نشانه‌گذاری ruby ساده‌تر و خواناتر باشد. مرورگر در نسخهٔ رندر شده، عنصر کامل را نمایش می‌دهد.
- به ازای هر بخش پایه / عنصر `<rb>` که می‌خواهید حاشیه‌نویسی کنید، باید یک عنصر {{HTMLElement("rt")}} نیز قرار دهید.

## مثال‌ها

### استفاده از rb

در این مثال، برای نویسه‌های معادل «کانجی» حاشیه‌نویسی ارائه شده است:

```html
<ruby>
  <rb>漢</rb><rb>字 </rb><rp>(</rp><rt>kan</rt><rt>ji</rt><rp>)</rp>
</ruby>
```

توجه کنید که دو عنصر `<rb>` برای جدا کردن دو بخش متن پایهٔ ruby به کار رفته است. حاشیه‌نویسی نیز با دو عنصر {{HTMLElement("rt")}} مشخص شده است.

### حاشیه‌نویسی جداگانه

می‌توان این مثال را طوری نوشت که دو بخش متن پایه کاملاً جداگانه حاشیه‌نویسی شوند. در این حالت نیازی به عناصر `<rb>` نیست:

```html
<ruby>
  漢 <rp>(</rp><rt>Kan</rt><rp>)</rp> 字 <rp>(</rp><rt>ji</rt><rp>)</rp>
</ruby>
```

برای مثال‌های بیشتر به مقالهٔ مربوط به عنصر {{HTMLElement("ruby")}} مراجعه کنید.
