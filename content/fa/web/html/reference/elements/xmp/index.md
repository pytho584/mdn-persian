## خلاصه

المان `<xmp>` در HTML متنی را که بین تگ شروع و پایان قرار دارد، بدون تفسیر HTML درون آن و با فونت monospace رندر می‌کند. مشخصات HTML2 توصیه کرده بود که این المان به اندازه‌ای عریض رندر شود که ۸۰ کاراکتر در هر خط جای بگیرد.

> [!NOTE]
> از این المان استفاده نکنید.
>
> - این المان از HTML3.2 منسوخ (deprecated) شده است و به‌صورت سازگار و یکنواختی پیاده‌سازی نشده بود. در HTML فعلی به‌طور کامل حذف شده است.
> - به جای آن از المان `<pre>` یا اگر از نظر معنایی مناسب است، از `<code>` استفاده کنید. توجه داشته باشید که برای جلوگیری از تفسیر شدن به عنوان markup، باید کاراکتر `<` را با `&lt;` و کاراکتر `&` را با `&amp;` escape کنید.
> - همچنین می‌توان با اعمال استایل CSS مناسب روی هر المانی فونت monospace به دست آورد؛ با استفاده از `monospace` به عنوان مقدار generic font برای ویژگی `font-family`.

## Attributes

این المان هیچ attribute دیگری به جز global attributes که برای همه المان‌ها مشترک است، ندارد.

## DOM interface

این المان اینترفیس `HTMLElement` را پیاده‌سازی می‌کند.

## بیشتر ببینید

- المان‌های `<pre>` و `<code>` را به جای آن استفاده کنید.
- المان `<plaintext>` مشابه `<xmp>` است اما آن نیز منسوخ شده است.
