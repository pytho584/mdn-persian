مقدار **`color-scheme`** برای ویژگی [`name`](/en-US/docs/Web/HTML/Reference/Elements/meta/name) در عنصر `<meta>`، یک طرح رنگ پیشنهادی را مشخص می‌کند که عامل کاربر (user agent) باید برای صفحه استفاده کند. اگر مشخص شده باشد، طرح رنگ را با استفاده از ویژگی [`content`](/en-US/docs/Web/HTML/Reference/Elements/meta#content) در عنصر `<meta>` و با یک مقدار CSS معتبر برای `color-scheme` تعریف می‌کنید.

این طرح رنگ در _سطح سند_ عمل می‌کند، همان‌طور که ویژگی CSS `color-scheme` طرح‌های رنگ ترجیحی و قابل قبول _عناصر منفرد_ را مشخص می‌کند. کاربرد اصلی `<meta name="color-scheme">` نشان دادن سازگاری و ترتیب اولویت برای حالت‌های روشن و تاریک است. برای مثال، برای نشان دادن اینکه سند حالت تاریک را ترجیح می‌دهد اما از حالت روشن نیز پشتیبانی می‌کند:

```html
<meta name="color-scheme" content="dark light" />
```

استایل‌های شما می‌توانند با استفاده از ویژگی رسانه‌ای `prefers-color-scheme` در CSS با طرح رنگ فعلی سازگار شوند.

## نکات استفاده

یک عنصر `<meta name="color-scheme">` ویژگی‌های اضافی زیر را دارد:

- [`content`](/en-US/docs/Web/HTML/Reference/Elements/meta#content)
  - : یک عنصر `<meta>` با `name=color-scheme` باید دارای ویژگی `content` باشد که طرح رنگ را به عنوان یک مقدار `color-scheme` در CSS تعریف کند. ویژگی `content` می‌تواند یکی از موارد زیر باشد:
    - `normal`
      - : سند از طرح‌های رنگ بی‌اطلاع است و باید با پالت رنگ پیش‌فرض نمایش داده شود.
    - `light`، `dark`، `light dark`، `dark light`
      - : یک یا چند طرح رنگ که توسط سند پشتیبانی می‌شود. وجود چند طرح رنگ نشان می‌دهد که طرح اول اولویت سند است، اما طرح دوم در صورتی که کاربر آن را ترجیح دهد قابل قبول است. مشخص کردن همان طرح رنگ چند بار همان اثر را دارد که یک بار مشخص شود.
    - `only light`
      - : نشان می‌دهد که سند _فقط_ از حالت روشن پشتیبانی می‌کند، با پس‌زمینه روشن و رنگ‌های متن تیره. `only dark` _نامعتبر است_، زیرا مجبور کردن سند به نمایش در حالت تاریک وقتی سازگار نیست می‌تواند به محتوای غیرقابل خواندن منجر شود و همه مرورگرهای اصلی به طور پیش‌فرض حالت روشن را دارند، مگر اینکه به گونه‌ای دیگر پیکربندی شده باشند.
- `media` (اختیاری)
  - : هر نوع رسانه یا media query معتبر. اگر ارائه شود، گزینه‌های طرح رنگ سند که در ویژگی `content` تعریف شده‌اند، زمانی که media query مطابقت داشته باشد به مرورگر پیشنهاد می‌شوند. این بیشتر برای ویژگی رسانه‌ای `prefers-color-scheme` در CSS مفید است.

## مثال‌ها

### استفاده از کلیدواژه color-scheme

مثال زیر به مرورگر نشان می‌دهد که صفحه از هر دو تم روشن و تاریک پشتیبانی می‌کند. اینکه از طرح رنگ روشن یا تاریک استفاده شود بستگی به ترجیحات کاربر دارد، مانند تنظیمات سطح سیستم‌عامل یا تنظیمات مرورگر:

```html
<meta name="color-scheme" content="light dark" />
```

## همچنین ببینید

- ویژگی CSS `color-scheme`
- media query `prefers-color-scheme` در CSS
