این عنصر (`<plaintext>`) هر چیزی که بعد از تگ شروع آن می‌آید را به‌عنوان متن خام (raw text) نمایش می‌دهد و هر تگ HTML بعدی را نادیده می‌گیرد. تگ پایانی ندارد، چون همه چیز بعد از آن متن خام محسوب می‌شود.

> **هشدار:** از این عنصر استفاده نکنید.
>
> - `<plaintext>` از HTML 2 به بعد منسوخ (deprecated) شده است و همه مرورگرها آن را پیاده‌سازی نکرده‌اند. مرورگرهایی که پیاده‌سازی کرده‌اند نیز رفتاری یکسان نداشتند.
> - `<plaintext>` دیگر کاربرد ندارد؛ مرورگرهایی که آن را می‌پذیرند ممکن است آن را معادل عنصر `<pre>` در نظر بگیرند که همچنان HTML درونش تفسیر می‌شود.
> - اگر `<plaintext>` اولین عنصر صفحه (به جز عناصر غیرنمایشی مثل `<head>`) است، اصلاً از HTML استفاده نکنید. در عوض، یک فایل متنی با MIME-type `text/plain` ارائه دهید.
> - به جای `<plaintext>` از عنصر `<pre>` یا (در صورت صحت معنایی، مثلاً برای متن درون‌خطی) از عنصر `<code>` استفاده کنید. کاراکترهای `<`، `>` و `&` را escape کنید تا مرورگر به‌اشتباه محتوای عنصر را به‌عنوان HTML تفسیر نکند.
> - می‌توان با استفاده از CSS و مقدار generic `monospace` در ویژگی `font-family`، فونت‌ِ monospace را به هر عنصر HTML اعمال کرد.

## ویژگی‌ها

این عنصر ویژگی دیگری جز [ویژگی‌های سراسری (global attributes)](/en-US/docs/Web/HTML/Reference/Global_attributes) ندارد.

## رابط DOM

این عنصر رابط `HTMLElement` را پیاده‌سازی می‌کند.
