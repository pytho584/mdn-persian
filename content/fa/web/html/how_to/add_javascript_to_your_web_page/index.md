## دربارهٔ جاوااسکریپت

جاوااسکریپت (JavaScript) یک زبان برنامه‌نویسی است که بیشتر در سمت کلاینت (client-side) استفاده می‌شود تا صفحات وب را تعاملی کند. بدون جاوااسکریپت هم می‌توانید صفحات وب شگفت‌انگیزی بسازید، اما جاوااسکریپت یک سطح کاملاً تازه از امکانات را پیش روی شما می‌گذارد.

> [!NOTE]
> در این مقاله کدهای HTML لازم برای اجرای جاوااسکریپت را بررسی می‌کنیم. اگر می‌خواهید خودِ جاوااسکریپت را یاد بگیرید، می‌توانید از مقالهٔ [مبانی جاوااسکریپت](https://developer.mozilla.org/en-US/docs/Learn_web_development/Getting_started/Your_first_website/Adding_interactivity) شروع کنید. اگر از قبل با جاوااسکریپت آشنایی دارید یا با زبان‌های برنامه‌نویسی دیگری کار کرده‌اید، پیشنهاد می‌کنیم مستقیم به [راهنمای جاوااسکریپت](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Guide) بروید.

## چطور جاوااسکریپت را از HTML اجرا کنیم؟

در مرورگر، جاوااسکریپت به‌تنهایی کاری انجام نمی‌دهد. شما جاوااسکریپت را از داخل صفحات HTML خود اجرا می‌کنید. برای اینکه کد جاوااسکریپت را از داخل HTML فراخوانی کنید، به عنصر `<script>` نیاز دارید. بسته به اینکه به یک اسکریپت خارجی لینک بدهید یا اسکریپت را مستقیم در صفحهٔ وب قرار دهید، دو روش استفاده از `script` دارید.

### اتصال یک اسکریپت خارجی

معمولاً اسکریپت‌ها را در فایل‌های جداگانه با پسوند `.js` می‌نویسید. اگر می‌خواهید یک اسکریپت `.js` را از صفحهٔ وب اجرا کنید، کافی است از `<script>` با ویژگی `src` استفاده کنید که به فایل اسکریپت و با استفاده از [URL](https://developer.mozilla.org/en-US/docs/Learn_web_development/Howto/Web_mechanics/What_is_a_URL) آن اشاره می‌کند:

```html
<script src="path/to/my/script.js"></script>
```

### نوشتن جاوااسکریپت داخل HTML

می‌توانید به‌جای تنظیم ویژگی `src`، کد جاوااسکریپت را بین تگ‌های `<script>` هم بنویسید:

```html
<script>
  console.log("Some code");
</script>
```

این روش وقتی راحت است که فقط به یک تکه‌کد کوچک جاوااسکریپت نیاز دارید. اما اگر جاوااسکریپت را در فایل‌های جداگانه نگه دارید، این‌ها را راحت‌تر خواهید داشت:

- تمرکز روی کار خودتان
- نوشتن HTML مستقل و خودکفا
- نوشتن اپلیکیشن‌های جاوااسکریپت با ساختار منظم

> [!NOTE]
> اسکریپت‌های داخلی (inline) و اسکریپت‌های خارجی که ویژگی [`defer`](https://developer.mozilla.org/en-US/docs/Web/HTML/Reference/Elements/script#defer) یا [`async`](https://developer.mozilla.org/en-US/docs/Web/HTML/Reference/Elements/script#async) ندارند، به‌محض اینکه مرورگر هنگام پردازش HTML به عنصر `<script>` برسد، اجرا می‌شوند. این یعنی اسکریپت به هیچ‌کدام از عناصر HTML که بعد از آن در سند آمده‌اند دسترسی ندارد. برای دسترسی به چنین عناصری، اسکریپت را به انتهای بدنهٔ سند (درست قبل از تگ بسته‌شدن `</body>`) منتقل کنید، یا برای اسکریپت‌های خارجی از ویژگی `defer` استفاده کنید.

## اسکریپت‌نویسی با رعایت دسترس‌پذیری

دسترس‌پذیری (accessibility) در هر توسعهٔ نرم‌افزاری موضوع مهمی است. جاوااسکریپت اگر درست استفاده شود می‌تواند سایت شما را دسترس‌پذیرتر کند، اما اگر بدون دقت اسکریپت‌نویسی کنید، می‌تواند فاجعه بیافریند. برای اینکه جاوااسکریپت به نفع شما کار کند، ارزش دارد که برخی از بهترین روش‌های افزودن جاوااسکریپت را بدانید:

- **تمام محتوا را به صورت متن (ساختاریافته) در دسترس قرار دهید.** تا جایی که ممکن است برای نمایش محتوا به HTML تکیه کنید. مثلاً اگر یک progress bar جذاب با JavaScript پیاده‌سازی کرده‌اید، حتماً درصدهای متنی متناظر را هم درون HTML قرار دهید. به همین ترتیب، منوهای کشویی (drop-down) شما باید به صورت [لیست‌های نامرتب](/en-US/docs/Learn_web_development/Core/Structuring_content/Lists#unordered_lists) از [لینک‌ها](/en-US/docs/Learn_web_development/Core/Structuring_content/Creating_links) ساختاردهی شوند.
- **تمام قابلیت‌ها را از طریق صفحه‌کلید قابل دسترس کنید.**
  - به کاربران اجازه دهید با کلید Tab به ترتیب منطقی میان تمام کنترل‌ها (مثل لینک‌ها و ورودی‌های فرم) حرکت کنند.
  - اگر از رویدادهای pointer (مانند رویدادهای ماوس یا لمسی) استفاده می‌کنید، همان قابلیت را با رویدادهای صفحه‌کلید هم پیاده‌سازی کنید.
  - سایت خود را فقط با صفحه‌کلید تست کنید.

- **محدودیت زمانی تعیین نکنید و حتی حدس نزنید.** پیمایش با صفحه‌کلید یا شنیدن محتوای خوانده‌شده زمان بیشتری می‌برد. تقریباً هرگز نمی‌توان پیش‌بینی کرد که کاربران یا مرورگرها چقدر طول می‌کشد تا یک فرآیند را کامل کنند (به‌ویژه عملیات ناهمگام مثل بارگذاری منابع).
- **انیمیشن‌ها را کوتاه و ملایم نگه دارید و از فلش (نور زدن) پرهیز کنید.** فلش زدن آزاردهنده است و می‌تواند [باعث تشنج شود](https://www.w3.org/TR/UNDERSTANDING-WCAG20/seizure-does-not-violate.html). همچنین اگر انیمیشنی بیش از چند ثانیه طول کشید، راهی برای لغو آن در اختیار کاربر بگذارید.
- **اجازه دهید کاربران تعاملات را شروع کنند.** یعنی محتوا را به‌طور خودکار به‌روزرسانی، تغییر مسیر (redirect) یا رفرش نکنید. بدون هشدار از carousel یا popup استفاده نکنید.
- **برای کاربرانی که JavaScript را غیرفعال کرده‌اند، یک راه جایگزین داشته باشید.** ممکن است افراد JavaScript را برای افزایش سرعت و امنیت خاموش کرده باشند، و کاربران اغلب با مشکلات شبکه‌ای مواجه می‌شوند که از بارگذاری اسکریپت‌ها جلوگیری می‌کند. علاوه بر این، اسکریپت‌های شخص ثالث (تبلیغات، اسکریپت‌های رهگیری، افزونه‌های مرورگر) ممکن است اسکریپت‌های شما را خراب کنند.
  - حداقل، یک پیام کوتاه با `<noscript>` بگذارید، مثلاً: `<noscript>برای استفاده از این سایت، لطفاً JavaScript را فعال کنید.</noscript>`
  - در حالت ایده‌آل، تا جایی که ممکن است قابلیت JavaScript را با HTML و اسکریپت‌نویسی سمت سرور تکرار کنید.
  - اگر فقط به دنبال جلوه‌های بصری ساده هستید، CSS اغلب می‌تواند حتی شهودی‌تر کار را انجام دهد.
  - _از آنجایی که تقریباً همه JavaScript را فعال دارند، `<noscript>` بهانه‌ای برای نوشتن اسکریپت‌های غیرقابل دسترس نیست._
