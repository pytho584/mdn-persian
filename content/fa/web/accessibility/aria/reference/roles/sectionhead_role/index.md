نقش **`sectionhead`**، یک نقش انتزاعی، نقش ابرکلاس برای برچسب‌ها یا خلاصه‌های موضوع بخش مرتبط با آن است.

> [!WARNING]
> نقش `sectionhead` یک [نقش انتزاعی](/en-US/docs/Web/Accessibility/ARIA/Reference/Roles#6._abstract_roles) است. اینجا برای تکمیل مستندات گنجانده شده است. نباید توسط نویسندگان وب استفاده شود.

## توضیحات

نقش ساختاری `sectionhead` یک نقش انتزاعی برای زیرکلاس‌ها است که برچسب‌ها یا خلاصه‌های بخش‌های مورد نظر را شناسایی می‌کنند. این نقش نباید استفاده شود. چهار زیرکلاس عبارتند از: [`columnheader`](/en-US/docs/Web/Accessibility/ARIA/Reference/Roles/columnheader_role)، [`heading`](/en-US/docs/Web/Accessibility/ARIA/Reference/Roles/heading_role)، [`rowheader`](/en-US/docs/Web/Accessibility/ARIA/Reference/Roles/rowheader_role)، و [`tab`](/en-US/docs/Web/Accessibility/ARIA/Reference/Roles/tab_role). معادل‌هایی از عناصر HTML وجود دارند، مانند {{HTMLElement('th', '<code>&lt;th scope="col"&gt;</code>')}} برای `columnheader`، {{HTMLElement('th', '<code>&lt;th scope="row"&gt;</code>')}} برای rowheader، و هر یک از عنوان‌های HTML، {{HTMLElement("Heading_Elements", "h1")}} تا {{HTMLElement("Heading_Elements", "h6")}} برای `heading`. نقش `tab` در حال حاضر معادل HTML ندارد.
