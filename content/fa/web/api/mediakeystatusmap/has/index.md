**`has()`** 方法属于 {{domxref("MediaKeyStatusMap")}} 接口，返回一个 {{jsxref('Boolean')}}，用于判断给定的键是否已关联了某个值。

## 语法

```js-nolint
has(key)
```

### 参数

- `key`
  - : 需要查询是否有关联值的键。

### 返回值

一个 {{jsxref('Boolean')}}。
