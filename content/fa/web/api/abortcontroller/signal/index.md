ویژگی فقط‌خواندنی **`signal`** در واسط [`AbortController`](/en-US/docs/Web/API/AbortController) یک نمونه از شیء [`AbortSignal`](/en-US/docs/Web/API/AbortSignal) را برمی‌گرداند که می‌توان از آن برای ارتباط با یک عملیات asynchronous یا لغو کردن آن، مطابق نیاز، استفاده کرد.

## Value

یک نمونه از شیء [`AbortSignal`](/en-US/docs/Web/API/AbortSignal).

## Examples

برای نمونه‌های استفاده، صفحهٔ [`AbortSignal`](/en-US/docs/Web/API/AbortSignal#examples) را ببینید.

می‌توانید یک [مثال کامل و عملی در GitHub](https://github.com/mdn/dom-examples/tree/main/abort-api) پیدا کنید؛ همچنین می‌توانید [نسخهٔ اجرایی زندهٔ آن](https://mdn.github.io/dom-examples/abort-api/) را نیز مشاهده کنید.
