ویژگی فقط‌خواندنی **`type`** در رابط {{domxref("HTMLOutputElement")}} رشتهٔ `"output"` را بازمی‌گرداند.

## مقدار

رشتهٔ `"output"`.

## مثال

```js
const output = document.querySelector("output");
console.log(output.type); // "output"
```
