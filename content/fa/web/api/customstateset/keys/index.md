{{APIRef("Web Components")}}

**`keys()`** 方法属于 {{domxref("CustomStateSet")}} 接口，是 {{domxref("CustomStateSet.values")}} 的别名。

## 语法

```js-nolint
keys()
```

### 参数

无。

### 返回值

一个新的迭代器对象，包含给定 `CustomStateSet` 中每个元素的值，按插入顺序排列。
