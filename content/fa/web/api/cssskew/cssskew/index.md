سازندهٔ **`CSSSkew()`** یک شیء جدید {{domxref("CSSSkew")}} می‌سازد که مقدار {{cssxref("transform-function/skew", "skew()")}} از ویژگی {{CSSXRef('transform')}} را در CSS نشان می‌دهد.

## Syntax

```js-nolint
new CSSSkew(ax, ay)
```

### Parameters

- {{domxref('CSSSkew.ax','ax')}}
  - : مقداری برای زاویهٔ `ax` (محور x) شیء {{domxref('CSSSkew')}} که قرار است ساخته شود. این مقدار باید یک {{domxref('CSSNumericValue')}} باشد.
- {{domxref('CSSSkew.ay','ay')}}
  - : مقداری برای زاویهٔ `ay` (محور y) شیء {{domxref('CSSSkew')}} که قرار است ساخته شود. این مقدار باید یک {{domxref('CSSNumericValue')}} باشد.
