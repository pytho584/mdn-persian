ویژگی **`HTMLTableElement.width`** نشان‌دهنده‌ی عرض مورد نظر جدول است.

## مقدار

یک رشته که عرض را به تعداد پیکسل یا به صورت درصدی نشان می‌دهد.

## مثال‌ها

```js
myTable.width = "75%";
```
