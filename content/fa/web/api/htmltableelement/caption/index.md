{{APIRef("HTML DOM")}}

ویژگی **`HTMLTableElement.caption`** نمایانگر عنوان (caption) جدول است. اگر هیچ عنصر `caption` با جدول مرتبط نباشد، مقدار این ویژگی `null` است.

## مقدار

یک رشته.

## مثال‌ها

```js
if (table.caption) {
  // Do something with the caption
}
```
