{{APIRef("HTML DOM")}}{{Deprecated_Header}}

ویژگی **`HTMLTableElement.align`** تراز جدول را نشان می‌دهد.

## مقدار

یکی از مقادیر رشته‌ای زیر:

- `left`
- `center`
- `right`

## مثال‌ها

```js
// Set the alignment of a table
const t = document.getElementById("TableA");
t.align = "center";
```
