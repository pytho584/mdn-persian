## مقدار

یک رشته.

## مثال‌ها

ثبت این ویژگی در کنسول، شناسه‌ای را که هنگام ثبت دریافت تنظیم شده بود برمی‌گرداند. در این مورد، `"my-fetch"`.

```js
console.log(bgFetch.id); // "my-fetch"
```
