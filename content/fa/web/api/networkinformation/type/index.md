خاصیت فقط‌خواندنی **`type`** در رابط {{domxref("NetworkInformation")}} نوع اتصالی را که دستگاه برای برقراری ارتباط با شبکه استفاده می‌کند، برمی‌گرداند.

## مقدار

یک مقدار شمارشی (enumerated) که یکی از مقادیر زیر است:

- `"bluetooth"`
- `"cellular"`
- `"ethernet"`
- `"none"`
- `"wifi"`
- `"wimax"`
- `"other"`
- `"unknown"`
