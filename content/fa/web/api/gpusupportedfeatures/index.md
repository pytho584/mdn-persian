رابط **`GPUSupportedFeatures`** از {{domxref("WebGPU API", "WebGPU API", "", "nocode")}} یک شیء [`Set`-مانند](/en-US/docs/Web/JavaScript/Reference/Global_Objects/Set#set-like_browser_apis) است که عملکردهای اضافی پشتیبانی‌شده توسط یک {{domxref("GPUAdapter")}} را توصیف می‌کند.

شیء `GPUSupportedFeatures` برای آداپتور فعلی از طریق ویژگی {{domxref("GPUAdapter.features")}} قابل دسترسی است — از این برای آزمایش اینکه چه ویژگی‌هایی توسط تنظیمات فعلی شما پشتیبانی می‌شود استفاده کنید. برای ایجاد یک {{domxref("GPUDevice")}} با یک ویژگی خاص فعال، باید آن را در آرایه [`requiredFeatures`](/en-US/docs/Web/API/GPUAdapter/requestDevice#requiredfeatures) توصیف‌کننده {{domxref("GPUAdapter.requestDevice()")}} مشخص کنید.

توجه داشته باشید که همه ویژگی‌ها در همه مرورگرهایی که WebGPU را پشتیبانی می‌کنند در دسترس نخواهند بود، حتی اگر ویژگی‌ها توسط سخت‌افزار زیرین پشتیبانی شوند. این می‌تواند به دلیل محدودیت‌های سیستم زیرین، مرورگر یا آداپتور باشد. به عنوان مثال:

- سیستم زیرین ممکن است نتواند نمایش یک ویژگی را به گونه‌ای تضمین کند که با یک مرورگر خاص سازگار باشد.
- فروشنده مرورگر ممکن است راه امنی برای پیاده‌سازی پشتیبانی از آن ویژگی پیدا نکرده باشد، یا ممکن است هنوز فرصت انجام آن را نداشته باشد.

اگر امیدوارید از یک ویژگی اضافی خاص در یک برنامه WebGPU استفاده کنید، آزمایش کامل توصیه می‌شود.

| `timestamp-query`                       | وقتی فعال باشد، اجازه اجرای پرس‌وجوهای زمانی (timestamp queries) را می‌دهد که زمان اجرای پاس‌های محاسباتی و رندر را اندازه‌گیری می‌کنند. اگر `timestamp-query` فعال باشد، مقدار `timestamp` می‌تواند برای ویژگی [`type`](/en-us/docs/Web/API/GPUDevice/createQuerySet#type) توصیف‌کننده {{domposer("GPUDevice.createQuerySet", "createQuerySet()")}} هنگام ایجاد یک {{domposer("GPUQuerySet")}} تنظیم شود. علاوه بر این، ویژگی `timestampWrites` می‌تواند بر روی توصیف‌کننده‌های {{domposer("GPUCommandEncoder.beginComputePass", "beginComputePass()")}} و {{domposer("GPUCommandEncoder.beginRenderPass", "beginRenderPass()")}} هنگام ایجاد به ترتیب یک {{domposer("GPUComputePassEncoder")}} و {{domposer("GPURenderPassEncoder")}} تنظیم شود. اشیاء `GPUQuerySet` در داخل اشیاء موجود در ویژگی `timestampWrites` ارجاع داده می‌شوند تا مشخص کنند زمان‌ها در کجا نوشته شوند.                                                                                                                                                                                                                                                                                     |

## ویژگی‌های نمونه (Instance properties)

ویژگی‌های زیر برای همه اشیاء خواندنی [`Set`-مانند](/en-US/docs/Web/JavaScript/Reference/Global_Objects/Set#set-like_browser_apis) در دسترس هستند (لینک‌های زیر به صفحه مرجع شیء سراسری {{jsxref("Set")}} اشاره دارند).

- {{jsxref("Set.prototype.size", "size")}}
  - : تعداد مقادیر موجود در مجموعه را برمی‌گرداند.

## روش‌های نمونه (Instance methods)

روش‌های زیر برای همه اشیاء خواندنی [`Set`-مانند](/en-US/docs/Web/JavaScript/Reference/Global_Objects/Set#set-like_browser_apis) در دسترس هستند (لینک‌های زیر به صفحه مرجع شیء سراسری {{jsxref("Set")}} اشاره دارند).

- {{jsxref("Set.prototype.has()", "has()")}}
  - : یک مقدار بولی برمی‌گرداند که نشان می‌دهد آیا عنصری با مقدار داده شده در مجموعه وجود دارد یا خیر.
- {{jsxref("Set.prototype.values()", "values()")}}
  - : یک شیء iterator جدید برمی‌گرداند که **مقادیر** هر عنصر در مجموعه را به ترتیب درج (insertion order) تولید می‌کند.
- {{jsxref("Set.prototype.keys()", "keys()")}}
  - : یک نام مستعار برای {{jsxref("Set.prototype.values()", "values()")}}.
- {{jsxref("Set.prototype.entries()", "entries()")}}
  - : یک شیء iterator جدید برمی‌گرداند که شامل **یک آرایه `[value, value]`** برای هر عنصر در مجموعه، به ترتیب درج است.
- {{jsxref("Set.prototype.forEach()", "forEach()")}}
  - : یک تابع callback ارائه شده را یک بار برای هر مقدار موجود در مجموعه، به ترتیب درج، فراخوانی می‌کند.

## مثال‌ها

```js
async function init() {
  if (!navigator.gpu) {
    throw Error("WebGPU not supported.");
  }

  const adapter = await navigator.gpu.requestAdapter();
  if (!adapter) {
    throw Error("Couldn't request WebGPU adapter.");
  }

  const adapterFeatures = adapter.features;

  // Return the size of the set
  console.log(adapterFeatures.size);

  // Check whether a feature is supported by the adapter
  console.log(adapterFeatures.has("texture-compression-astc"));

  // Iterate through all the set values using values()
  const valueIterator = adapterFeatures.values();
  for (const value of valueIterator) {
    console.log(value);
  }

  // Iterate through all the set values using keys()
  const keyIterator = adapterFeatures.keys();
  for (const value of keyIterator) {
    console.log(value);
  }

  // Iterate through all the set values using entries()
  const entryIterator = adapterFeatures.entries();
  for (const entry of entryIterator) {
    console.log(entry[0]);
  }

  // Iterate through all the set values using forEach()
  adapterFeatures.forEach((value) => {
    console.log(value);
  });

  // …
}
```
