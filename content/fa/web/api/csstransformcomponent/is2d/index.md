ویژگی **`is2D`** از رابط {{domxref("CSSTransformComponent")}} مشخص می‌کند که تبدیل (transform) دو بعدی است یا سه بعدی.

## مقدار

یک مقدار بولی. اگر تبدیل دو بعدی باشد `true` و اگر سه بعدی باشد `false`.
