{{APIRef("HTML DOM")}}

این متد همیشه `false` برمی‌گرداند.

## سینتکس

```js-nolint
javaEnabled()
```

### پارامترها

هیچ پارامتری ندارد.

### مقدار بازگشتی

مقدار بولی `false` است.

## مثال‌ها

```js
if (window.navigator.javaEnabled()) {
  // code will never be executed; the condition is always false
}
```
