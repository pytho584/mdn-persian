{{APIRef("HTML DOM")}}

ویژگی **`target`** در رابط {{domxref("HTMLFormElement")}}، هدف اکشن فرم را مشخص می‌کند (یعنی فریمی که خروجیِ فرم در آن نمایش داده می‌شود).

## مقدار

یک رشته.

## مثال‌ها

```js
myForm.target = frames[1].name;
```
