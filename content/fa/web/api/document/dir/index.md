ویژگی **`Document.dir`** یک رشته است که جهت‌گیری متن سند را نشان می‌دهد، خواه چپ‌به‌راست (پیش‌فرض) یا راست‌به‌چپ. مقادیر ممکن عبارتند از `'rtl'` (راست‌به‌چپ) و `'ltr'` (چپ‌به‌راست).

## مقدار

یک رشته.
