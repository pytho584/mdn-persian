خاصیت فقط خواندنی **`bottom`** از رابط **`DOMRectReadOnly`** مقدار مختصات پایینی `DOMRect` را برمی‌گرداند. (مقدار آن برابر است با `y + height`، یا اگر `height` منفی باشد، برابر با `y` است.)

## مقدار

یک عدد double.
