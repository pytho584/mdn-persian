هنگام برنامه‌نویسی برای وب، Web APIهای زیادی در دسترس شماست. در ادامه فهرستی از همه APIها و interfaceها (انواع object) که می‌توانید در توسعه‌ی وب‌اپلیکیشن یا سایت خود استفاده کنید آورده شده است.

Web APIها معمولاً با جاوااسکریپت استفاده می‌شوند، اگرچه همیشه اینطور نیست.

## مشخصات

در اینجا فهرست تمام APIهای موجود آمده است.

## Interfaceها

در اینجا فهرست تمام interfaceهای موجود (یعنی انواع object) آمده است.
