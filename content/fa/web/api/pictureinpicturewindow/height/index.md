{{APIRef("Picture-in-Picture API")}}

ویژگی فقط‌خواندنی **`height`** از رابط {{domxref("PictureInPictureWindow")}} ارتفاع پنجره ویدیوی شناور را بر حسب پیکسل برمی‌گرداند.

## مقدار

یک مقدار صحیح که ارتفاع پنجره ویدیوی شناور را بر حسب پیکسل نشان می‌دهد، در صورتی که پنجره تصویر-در-تصویر باز باشد. در غیر این صورت، `0` برمی‌گرداند.
