{{APIRef("CSS Font Loading API")}}{{AvailableInWorkers}}

**`values()`** 方法属于 {{domxref("FontFaceSet")}} 接口，返回一个新的迭代器对象，该对象会按插入顺序生成 `FontFaceSet` 对象中每个元素的值。

## 语法

```js-nolint
values()
```

### 参数

无。

### 返回值

一个新的迭代器对象，包含给定 `FontFaceSet` 中每个元素的值，顺序为插入顺序。
