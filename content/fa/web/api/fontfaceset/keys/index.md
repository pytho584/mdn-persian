{{APIRef("CSS Font Loading API")}}{{AvailableInWorkers}}

**`keys()`** 方法属于 {{domxref("FontFaceSet")}} 接口，是 {{domxref("FontFaceSet.values")}} 的一个别名。

## 语法

```js-nolint
keys()
```

### 参数

无。

### 返回值

一个按照插入顺序包含给定 `FontFaceSet` 中每个元素值的新的迭代器对象。
