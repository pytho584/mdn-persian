{{APIRef("Force Touch Events")}}{{Non-standard_header}}

**`MouseEvent.WEBKIT_FORCE_AT_MOUSE_DOWN`** یک ویژگی عددی ایستا و اختصاصیِ مخصوص WebKit است که مقدار آن، حداقل نیروی لازم برای یک کلیک معمولی را نشان می‌دهد.

از آنجا که `WEBKIT_FORCE_AT_MOUSE_DOWN` یک ویژگی ایستای `MouseEvent` است، همیشه باید آن را به صورت `MouseEvent.WEBKIT_FORCE_AT_MOUSE_DOWN` استفاده کنید، نه به عنوان ویژگیِ یک نمونه از `MouseEvent`.

## مشخصات

_بخشی از هیچ specification نیست._ اپل [توضیحاتی در Mac Developer Library](https://developer.apple.com/library/archive/documentation/AppleApplications/Conceptual/SafariJSProgTopics/RespondingtoForceTouchEventsfromJavaScript.html) ارائه کرده است.
