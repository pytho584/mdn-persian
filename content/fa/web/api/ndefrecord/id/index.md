**`id`** ویژگیِ رابط {{DOMxRef("NDEFRecord")}} شناسۀ رکورد را برمیگرداند؛ شناسهای که یک URL مطلق یا نسبی برای شناسایی رکورد است.

این شناسه توسط سازندۀ رکورد ایجاد میشود و مسئولیت تضمین یکتایی شناسۀ رکورد نیز بر عهدۀ اوست. Web NFC محتوای NFC را امضا نمیکند، بنابراین مصرفکنندۀ رکورد نباید هیچ فرضی دربارهٔ یکپارچگی یا اصالت شناسه یا هر بخش دیگری از رکوردها داشته باشد.
