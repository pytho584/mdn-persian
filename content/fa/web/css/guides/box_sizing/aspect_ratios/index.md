# درک و تنظیم نسبت‌های ابعاد (aspect ratio)

هر عنصری که در صفحه رندر می‌شود، دارای ارتفاع و عرض است و در نتیجه، یک {{glossary("aspect ratio", "نسبت ابعاد")}} دارد که نسبت بین عرض و ارتفاع است. ابعاد طبیعی یک شیء رسانه‌ای، که اندازه‌ی آن بدون اعمال هیچ اندازه‌گیری، مقیاس، بزرگ‌نمایی یا حاشیه‌ای است، به عنوان اندازه‌ی طبیعی یا {{glossary("intrinsic size", "اندازه‌ی ذاتی")}} آن شناخته می‌شود. اندازه‌ی ذاتی یک عنصر توسط خود عنصر تعیین می‌شود، نه با اعمال قالب‌بندی مانند [اندازه‌گیری جعبه](/fa/docs/Web/CSS/Guides/Box_sizing) یا تنظیم عرض حاشیه، padding یا margin.

هنگام توسعه‌ی وب‌سایت‌ها، اغلب می‌خواهید بتوانید عرض یک عنصر را به صورت درصدی از اندازه‌ی viewport یا ظرف والد تنظیم کنید و ارتفاع نیز به‌طور متناسب تغییر کند، بنابراین نسبت ابعاد مشخصی را بسته به اندازه‌ی viewport حفظ کند. برای عناصر جایگزین‌شده (replaced elements) مانند تصاویر و ویدیوها، حفظ نسبت ابعاد مشخص نه تنها برای ایجاد {{glossary("responsive web design", "طراحی وب واکنش‌گرا")}} ضروری است، بلکه بخش مهمی از ارائه‌ی تجربه‌ی کاربری خوب است. تنظیم نسبت ابعاد یک دارایی، از [لرزش چیدمان (jank)](/fa/docs/Learn_web_development/Extensions/Performance/Multimedia#rendering_strategy_preventing_jank_when_loading_images) جلوگیری می‌کند — تغییری در چیدمان که وقتی رسانه پس از بارگذاری صفحه بارگذاری می‌شود رخ می‌دهد و باعث بازچینش (reflow) می‌شود، زیرا فضای آن دارایی رزرو نشده است.

با استفاده از CSS، می‌توانید اندازه‌ی عناصر جایگزین‌شده و غیرجایگزین‌شده را بر اساس نسبت ابعاد آن‌ها تنظیم کنید. در این راهنما، با ویژگی `aspect-ratio` آشنا می‌شویم، نسبت‌های ابعاد را برای عناصر جایگزین‌شده و غیرجایگزین‌شده بررسی می‌کنیم و سپس برخی از موارد استفاده‌ی رایج نسبت ابعاد را مرور می‌کنیم.

## نحوه‌ی عملکرد ویژگی `aspect-ratio`

مقدار ویژگی CSS {{cssxref("aspect-ratio")}}، نسبت عرض به ارتفاع ترجیحی جعبه‌ی یک عنصر را تعریف می‌کند. مقدار آن یا یک {{cssxref("ratio")}}، کلیدواژه‌ی `auto`، یا ترکیبی با فاصله از هر دو است.

`<ratio>` نسبت عرض به ارتفاع است، به همین ترتیب. با دو مقدار مثبت {{cssxref("number")}} که با اسلش (`/`) از هم جدا شده‌اند یا یک عدد `<number>` نشان داده می‌شود. وقتی از یک عدد استفاده می‌شود، معادل نوشتن نسبت به صورت `<number> / 1` است که همان عرض تقسیم بر ارتفاع است.

مقادیر زیر همگی معادل هستند:

```css
aspect-ratio: 3 / 6;
aspect-ratio: 1 / 2;
aspect-ratio: 0.5 / 1;
aspect-ratio: 0.5;
